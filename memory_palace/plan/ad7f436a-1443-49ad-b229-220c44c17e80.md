# 计划文档

## 计划

1. 【本期范围】打通「web 页」最小闭环：dev-task 计划文档页（统一键 sessionId）+ 短期 token 鉴权 + cloudflared 公网可达 + QQ 短链替换长文推送；game 资源页（/tabletop_game/{gameId}/player/{qqid}）因引擎未实现，本期做骨架占位页（返回『暂未开放』），保持路由完整
2. 【目标链路】QQ #开发 → 受理(含 sessionId) → 子会话生成计划文档落盘 → agent-gateway 调 server auth 签发短期 token → 拼短链 https://{域名}/dev_task/{sessionId}?token=xxx → QQ 推短链 → 玩家点开 → cloudflared → web(Express) 服务端调 server /auth/verify 校验 → server 读 plan 文件返回 markdown → web 渲染 HTML
3. 【分层实现-1】crates/auth：短期 token 签发/校验（uuid token + TTL 可配 + 绑定 member_openid + 只读资源范围），经 server 暴露 HTTP API
4. 【分层实现-2】crates/server：新增 POST /auth/issue、POST /auth/verify、GET /resources/dev_task/{sessionId}/plan、GET /resources/game/{gameId}（占位）；sessionId/路径严格白名单校验（uuid 格式，防路径穿越）
5. 【分层实现-3】apps/web：Express BFF，路由 /dev_task/{sessionId}?token=xxx（+ /tabletop_game/{gameId}/player/{qqid}?token=xxx 占位）；服务端调 server 鉴权+拉取，markdown(GFM) 渲染 HTML；trust proxy 处理 CF-Connecting-IP/X-Forwarded-For
6. 【分层实现-4】apps/agent-gateway：短链生成（PUBLIC_BASE_URL + 已签发 token）替换 >1500 字六分区计划长文分段推送；新增到 server 的 HTTP 客户端（issue token）
7. 【分层实现-5】cloudflared 部署：Cloudflare 命名隧道 + 自有域名(托管 CF DNS) + ingress 反代到 http://127.0.0.1:WEB_PORT + 常驻运行（Windows 服务或 Docker）+ 大陆可达性实测记录
8. 【安全约束】token 仅短期、绑定身份、只读用途、HTTPS 由隧道提供；web 不直连 SQLite/文件，统一经 server 查询 API；穿越层只解决可达、不替代应用层鉴权
9. 【数值约束标注】token TTL 默认值、Cloudflare 大陆可达性均为『待验证』假设，实测后回填 external-constraints.md，不得写死为实现约束
