# 工作台：创建对局（沙盒开局）调研与计划

## 计划

1. 【结论】可行，且**不需要改动 Q 群消息驱动开局**。建议把「创建对局」实现为**工作台预览会话**（`preview:<uuid>`，独立内存态、不写 `game_state`/`game_events`），而不是真实线上房间；Q 群 `#开局/#加入/#开始` 流程零改动。
2. 【实现路线】引擎新增沙盒开局原语：`SanguoshaEngine` 侧 `new_sandbox_game(room/group, spec, rng)`；把现有 `finish_setup` 内部拆为 `assign_generals_from_picks` + `start_after_setup`，Q 流程继续走原函数，行为不变；沙盒直接设置座位（玩家数/武将/身份/is_bot）后调用同一个 `start_after_setup`，因此**开局技能（化身/怀橘/宗祚/血裔/巧变/明任）与随机牌堆/手牌走同一条生产逻辑**。
3. 【身份】按标准身份配比（5–8 人，`identity_list(n,false)`）做「按座位指定 + 剩余随机」：用户选的身份从池中扣除；超过配比报错；未选座位随机填充；保证恰好 1 主公。
4. 【武将】表单按座位选择，非必填；已选武将**按 code 去重**，其他座位候选项置灰（或过滤）；未选座位从剩余武将池随机（不重复）。武将列表由引擎只读元数据提供（name/code/kingdom/max_hp/pack/is_lord/skills）。
5. 【座位】玩家数 5–8；座位 `#1..#N`；全部 `is_bot=true`；玩家 id 默认 `bot:1..N`（可请求覆盖，服务端校验唯一）。创建后状态为 `phase=turn / turn_phase=play`（或主公的开局 pending），手牌 4 张、牌堆按 `Config.packs`（默认 standard+junzheng）随机洗牌。
6. 【API】新增（均 `require_admin`，经现有 web `/internal/game/preview/*` 代理）：
   - `GET /internal/game/preview/meta`：玩家数、可实装武将列表、身份配比；
   - `POST /internal/game/preview/sandbox`：`{players, seats:[{index,general?,identity?}], seed?, save_template?, name?}` → 创建预览会话（可选保存模板）并返回视图。
7. 【UI】模板 TAB 增加「创建对局」按钮 → `n-drawer` 抽屉表单：玩家数必填；按人数渲染 `#1..#N` 行，每行「武将（可搜索、按名称子串匹配、其他座位已选置灰）+ 身份（剩余配比置灰）」；可选随机种子、保存为模板；提交后直接切到预览 TAB 并加载 iframe。
8. 【不做什么】不改 Q 群命令/消息路由；不新增真实房间；不生成代码；不改线上对局写路径；不引入新的外部依赖。
9. 【验收】引擎单测（指定/随机/重复/配比/守恒/开局技能）；API harness（创建→座位/身份/武将/手牌/牌堆/全 bot→AI 推进→隔离断言）；UI 抽屉冒烟；现有 `sgs:check` 全绿。

## 待确定事项

- 【阻塞 1｜座位范围】「按玩家人数分别选择 #5-8 号位」是指 **#1–#N 每个座位都可指定**，还是只允许 #5–#8 号位指定、其余随机？（按上下文推测应为 #1–#N）
- 【阻塞 2｜创建位置】创建的是**工作台预览会话**（推荐：独立内存、不写库、不影响 Q），还是**真实线上房间**（会改 Q/DB 流程，工作量大且风险高）？
- 【阻塞 3｜身份规则】是否按标准配比（5 人 1 主 1 忠 2 反 1 内；6/7/8 人按 `identity_list`）并允许按座位指定？还是允许任意身份组合（会破坏胜负/主公规则）？
- 【阻塞 4｜武将池】表单展示/随机使用 **232 位已实装武将**（允许原版与界版同场），还是沿用正常选将池的 **149 位去重池**（界优先）？
- 【阻塞 5｜模板】创建后只生成预览会话，还是默认保存一条模板（便于复用）？建议：默认只创建会话，提供「保存为模板」开关（默认关）。
- 【阻塞 6｜搜索口径】「按武将名称最小子串匹配」理解为**名称包含输入子串（不区分大小写）**，是否还需匹配 code/拼音？
- 【阻塞 7｜牌堆/包】不提供包选择，固定 `Config.packs = standard+junzheng`、武将包默认全量；是否接受？
- 【阻塞 8｜随机种子】是否增加可选「随机种子」输入（便于复现，默认自动随机）？
- 【阻塞 9｜全 bot 后操作】创建后停在主公的 `play`/pending，不自动 AI 连推；由工作台手动「AI 单步/连推」或代操作。是否接受？
- 【阻塞 10｜开局技能】指定武将的开局技能按正常流程执行（如左慈化身、陆绩怀橘、刘虞宗祚、界袁绍血裔、界张郃巧变、卢植明任）；是否接受这些额外状态出现在初始局面？
