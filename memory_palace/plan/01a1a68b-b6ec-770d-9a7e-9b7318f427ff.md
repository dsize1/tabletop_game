# 计划文档

## 计划

1. 范围（本轮）：把 `data/media/sgs/out/final/` 的 534 张 512×720 卡面「入中台」——素材落盘/上传、缩略图、裁剪、`prop_assets` + `image_asset_id` 绑定、Web 对局页展示。不做卡面再生成、不加公网新入口、不改引擎规则。
2. 存储与访问（推荐方案 A）：素材 = 内容寻址文件；`prop_assets.path` 存相对路径 `sanguosha/general/<sha256前16>.webp`，`thumb_path` 同目录 `<hash>.t.webp`。server 独占写入 `GAMEPROPS_ASSETS_DIR`（默认 `data/gameprops/assets`，`/data/` 已 gitignore）；web 以 `/game-assets` 静态挂载同一目录（文件名哈希 → immutable 一年），浏览器仍不直连 server。
3. 数据模型：`prop_assets` 幂等增列 `thumb_path / thumb_width / thumb_height / crop_json / original_name`，同步更新白名单列；不建新表。绑定仍只写 `image_asset_id`（现有 upsert 是 `ON CONFLICT DO UPDATE` 局部更新，不会清空其他列）。
4. server API（全部 `require_admin`，asset-map 供 web 带共享 token 内部调用）：`POST /internal/gameprops/assets/upload`（raw body + query: game_id/kind/mime/width/height/filename/crop；sha256 去重 + 原子写盘）；`POST /internal/gameprops/assets/{id}/thumb`；`GET /internal/gameprops/assets`（分页/kind 筛选）；`GET /internal/gameprops/asset-map?game_id=&kind=`（code→url，join `sgs_generals.image_asset_id`）；`POST /internal/gameprops/bind-asset`（table + code/id + asset_id|null，校验表/资产存在）；`DELETE /internal/gameprops/assets/{id}`（被引用则拒绝）。
5. 安全与校验：路径只由 sha256 + mime 扩展名生成（绝不使用客户端文件名）；`game_id`/`kind` 白名单正则；mime 只允许 webp/jpeg/png；尺寸 1–4096；full ≤8MB、thumb ≤1MB；`crop_json` 只存解析后的数字矩形；删除/写盘做目录穿越防护。
6. props-admin「素材」页（`/assets`）：缩略图网格 + kind 筛选 + 搜索；上传对话框 = 文件 → canvas 裁剪（拖拽平移 + 缩放滑块 + 武将固定 512:720 比例）→ 导出 webp(q0.82) + 256×360 缩略图(q0.78)，浏览器不支持 webp 编码时回退 png/jpeg；支持预览、删除、复制路径。
7. props-admin 绑定：`/generals` 列表增「卡面」列（缩略图 / 未绑定）+「选择素材」抽屉（同 kind 缩略图 + 搜索），保存写 `image_asset_id`；`/card-defs`、`/identities`、`/cards` 接同一组件（本轮先武将，其余同构接入）；「上传并绑定」一步完成。
8. 批量导入脚本 `apps/scripts/import-sgs-general-assets.mjs`：读 `data/media/sgs/out/final-manifest.json` → sharp 生成 webp(512×720,q82)+thumb(256×360,q78) → 调 server 上传（按 sha256 幂等）→ 按 manifest `gids` 绑 `sgs_generals.code='sgs_hero_<gid>'`（manifest 覆盖 696 gid；DB 有多少行绑多少）→ 输出 report（上传/去重/绑定/未绑定/未覆盖桶）。支持 `--dry-run`、`--limit`、`--manifest`。
9. Web 展示：web 新增 `fetchAssetMap()`（调 server `asset-map`，内存缓存 60s，失败降级无图）；`renderSgsPage` 把 map 传入 `renderPublicArea / renderPersonalArea / renderGeneralDetail`；bootstrap JSON 带 `assets` 供客户端轮询重渲染。展示位置：① 其他玩家座位卡 ② 本人武将区头部 ③ 选将候选卡片 ④ 武将详情浮层；无图回退势力色占位，绝不出现裂图。
10. 文档与门禁：更新 `docs/modules/props-admin.md`（素材页/API/环境变量/边界）、`docs/modules/web.md`（`/game-assets` 缓存口径）、`docs/games/sanguosha/props/media-pipeline.md` §16、`docs/games/sanguosha/data-model.md`（image 字段启用）；新增 ADR-0036（素材入库与公网可见边界）并登记 `decisions/README.md`；新增 `npm run check:sgs-assets`（临时 server+web+临时 SQLite/资产目录：上传→缩略图→绑定→asset-map→`/game-assets` 200+immutable+未知哈希 404+越权 401），并把 `/game-assets` 断言加进 `check:props-boundary`。
11. 验收口径：批量导入后 `/assets` 534 张；`/generals` 232 行有卡面（若已导入官网 696 则 696 行）；对局页（含工作台预览）所有已选武将均显示头像；8 人局首屏缩略图总体积 ≤250KB；`npm run build:props`、`npm run test:web`、`npm run check:props-boundary`、`npm run check:sgs-assets` 全绿。
