# 计划文档

## 计划

1. 【范围与边界（按 2026-11-03 裁定）】本轮「工作台」只做基座四件套：模板 / 预览 / AI 调试 / 决策日志，用于批量验证武将；**不做** n8n/Vue Flow 有向图编排与代码生成（留待武将验证后另立 ADR）。工作台是**只读仿真宿主**：独立内存态、不写 `game_state`/`game_events`/`game_decision_log`，不参与线上对局（ADR-0018）。
2. 【存储】新增 `crates/storage/src/templates.rs`：`game_state_templates` 建表（data-model §5 字段）+ `(game_id)` 索引；CRUD（create/list/get/update/delete/duplicate）+ 输入校验（name 非空、snapshot 为 JSON 对象、source 格式）；单测覆盖幂等建表/CRUD/复制/删除。
3. 【引擎钩子】`game-engine-core::EnginePlugin` 增加默认方法：`validate_state(&GameState)->Result<(),String>`（默认 Ok）与 `apply_scene(&GameState,&Value)->Result<GameState,String>`（默认不支持）；`sanguosha` 实现：反序列化 SgsState + `check_conservation` + 武将/技能 code 存在性；场景按白名单注入（座位武将/身份/体力/上限/横置/标记/手牌/装备/判定区、回合/阶段/轮次、牌堆顶、种子、计数器），卡牌只能从现有实例移动，注入后再次守恒校验。
4. 【预览宿主】新增 `crates/server/src/preview.rs`：`PreviewManager`（`HashMap<uuid, PreviewSession>`，每会话独立 `GameManager` + 串行锁 + 步骤时间线）；房间号强制 `preview:<uuid>`、不注册 `active_by_group`、不落库；空闲 TTL 2h、单进程上限 8 个会话（env 可调）。
5. 【预览 API（本机 + props 白名单/共享 token）】`POST /internal/game/preview`（template_id 或 inline snapshot + scene）→ `preview_id` + 公共区/个人区/合法动作；`GET /internal/game/preview/{id}?viewer=&mode=public|player|raw`；`POST .../{id}/action`（任意座位可代操作，工作台语义）；`POST .../{id}/drive`（AI 单步/连推，策略 heuristic|random）；`POST .../{id}/reset`；`DELETE .../{id}`。
6. 【AI 调试】复用 `sanguosha::ai::driver::drive_bots`（persist 仅写内存步骤）+ `policy::decide_traced` 单步；回传每步 actor/legal/candidates/chosen/priority/score/reason/latency/state_digest；预览轨迹只存在会话内存，不写 `game_decision_log`。
7. 【Web 预览页】`GET /tabletop_game/:gameId/preview?room=preview:<uuid>&viewer=<player_id>`：走 `propsSession` 门禁（不要求 `game:` token）；复用 `renderSgsPage` 三分区与现有客户端，新增 preview 模式（轮询/提交走预览代理、无 token）；工具栏：视角切换、AI 单步、AI 连推、重置、关闭；非白名单 403、未知/过期 404。
8. 【Web 代理】新增 `/internal/game/preview/*` 代理（与 `/internal/gameprops/*` 同门禁：`propsSession` → 透传 `x-props-actor` → server 二次校验）；预览页与 API 均不进入 `game:` token 体系。
9. 【工作台页面】`apps/props-admin/src/pages/WorkbenchPage.vue` + 路由 `/workbench` + 侧栏「工作台」，四个 TAB（keep-alive 保留状态）：①模板（列表/筛选、从对局房间抓取、JSON 导入、复制、删除、导出、来源展示）；②预览（选模板→创建/重置/销毁，iframe 嵌入预览页，展示 preview_id）；③AI 调试（raw 状态、当前行动者合法动作、单步并展示候选/打分/理由、连推、步骤时间线）；④决策日志（按 game/room/since 只读查询 + 导出 JSONL）。
10. 【决策日志只读 API】`GET /internal/gameprops/decision-logs?game_id=&room_id=&since_seq=&limit=`（`require_admin`）复用 `storage.list_decision_logs`；返回字段与导出脚本口径一致（player_id 默认哈希，避免工作台二次泄露 openid）。
11. 【文档】新增 ADR-00xx「工作台基座与预览隔离」（范围收缩/独立内存态/引擎钩子/单写者边界）；更新 `docs/modules/props-admin.md`（页面/API/准入）、`docs/modules/game-engine.md`（预览宿主/引擎钩子）、`docs/games/sanguosha/data-model.md`（模板 API/预览不落库）、`docs/games/sanguosha/development-plan.md`（P5 实施记录）、`memory_palace/milestones.md`（M61）。
12. 【门禁】`cargo test -p storage -p sanguosha -p server`、`npm run build:props`、`npm run test:web`、`npm run test:sgs-web`、`npm run sgs:check:fast`、`npm run check:props-boundary`（补预览代理条款）、新增 `npm run check:sgs-preview`；主动推送检查脚本（本轮无主动推送）。
13. 【明确不做】n8n/Vue Flow 图编辑器、图→代码生成、模板公网分享、预览状态持久化/跨重启恢复、预览写真相源、多用户并发预览协作。
