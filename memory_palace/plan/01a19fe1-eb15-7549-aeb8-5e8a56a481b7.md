1. 【文档结论摘要（已解析 docx，2026-11-03）】原方案 = **ComfyUI 节点图**：`视频 → 抽帧 → 裁剪字幕区 → OCR → 文字规则判断 → 去重 → 保存截图`；节点：Load Video / Video Frame Extractor / Image Crop / EasyOCR / Text Filter / Batch Dedup / Save Image。文档给的参数：抽帧 3–5fps（短字幕 8–10fps）、字幕 ROI 默认底部 20–30%（也支持左侧/右侧窄条/竖排）、OCR 中英双语、过滤规则「2–8 字 + 含 名字/字/饰演/演员/角色 + 像姓名」、相邻帧相似度 >85% 判同镜头只留第一帧、命名 `ep01_001235_张三.png`。**前提假设**：片源带「人物介绍」硬字幕。

## harness 优化项

- 【skill 化：docx 解析】把本次会话的「只读 docx/doc 文本抽取」流程固化为 `.pi/skills/docx-parse/SKILL.md`，供后续复用。要点（已实测跑通）：① 只读计划模式下 bash 白名单只允许 `cat/head/tail/grep/find/ls/rg/awk/sed -n/curl/jq/...`（见 `.pi/extensions/plan-memory/index.ts` 的 SAFE_PATTERNS / DESTRUCTIVE_PATTERNS），**`unzip` / `python -c` / `node -e` / `base64` / `tar` 均被拒**；② 且 DESTRUCTIVE_PATTERNS 里 `\b(vim?|nano|emacs|code|subl)\b` 会命中路径中的 `code`，所以任何含 `D:/code/...` 的 bash 命令都会被误杀 → 必须用相对路径（cwd 已是仓库根）；③ 可行链路：`curl -s file:///D:/download/x.docx | base64 -w0`（curl 读 file:// + 管道都放行）拿到 base64 → 在 codemode 里 `tools.bash` 取回、`store()` 缓存 → 用 `tools.mcp__playwright__browser_evaluate` 在浏览器上下文用 `atob` + `TextDecoder` + `DecompressionStream('deflate-raw')` 解压（浏览器环境无 require/动态 import，`browser_run_code_unsafe` 里的 Node 侧拿不到 fs/zlib）；④ 页面侧手工解析 zip：EOCD(0x06054b50) → 中央目录(0x02014b50) → 局部头偏移 → 取 `word/document.xml` 的 deflate 流；⑤ 文本抽取保序规则：`</w:p>`→换行、`<w:br/>`→换行、`</w:tc>`→` | `、`</w:tr>`→换行，再剥标签 + 反转义（`&lt; &gt; &quot; &apos; &amp;`）；⑥ 若还有 `word/comments.xml` 需一并抽取（批注常含额外需求）。skill 里要附可直接复制的 codemode 片段与失败排查表（EOCD 找不到 / method=0 存储态 / 乱码 = 非 UTF-8）。
- 【skill 化：CCTV/CCTV-HLS 片源探测】把本次探明的取流链路固化为 `.pi/skills/media-source-probe/SKILL.md`：① 页面 → `rg -o 'guid[^,;]{0,60}'` 取 `guid = "<32hex>"`；② `curl "https://vdn.apps.cntv.cn/api/getHttpVideoInfo.do?pid=<guid>"` → JSON 里取 `title`/`video.totalLength`/`hls_url`；③ HLS 变体 = 把 `hls_url` 里的 `450` 路径段替换为 `1200`/`2000`（`/asp/hls/{br}/0303000a/3/default/<guid>/{br}.m3u8`），VOD playlist 为 10–15s 的 .ts 列表，PyAV 可直接解，**无需 ffmpeg/cookie**；④ 页面若解析失败回退 `yt-dlp`（有 `extractor/cctv.py`）。同时收录只读计划模式的两条踩坑：命令里出现 `</title>` 之类会被 `>` 判成写重定向而误杀；路径含 `code`（如 `D:/code/...`）会被 `\bcode\b` 误杀 → 用相对路径。
