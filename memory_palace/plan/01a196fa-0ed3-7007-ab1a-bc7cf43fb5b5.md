# 计划文档

## 计划

1. **背景与边界**：暂不具备 QQ 扫码登录条件（无法备案 + QQ 互联「在线游戏应用暂不合作」+ 群事件 `union_openid` 实测为空），改为**系统自建跨端确认权鉴**：Web 端用「注册码」证明身份记忆，Q 群端用 `#验证码#NNNN` 证明群身份控制权，两端口令同源（同一会话）才发放正式 token。
2. **核心机制（用户 2026-11-01 定稿）**：**短效登录会话 = token + 状态 + 4 位码 + 目标路由，四者同生命周期**（同一 Redis 记录、同一 TTL；阶段转换时续期）。登录页 URL 只带短效 token：`/login?t=<token>`；记录内 `target` 决定确认后跳转的**路由**（游戏个人页 / `/props-admin/`），因此登录链接与游戏链接**同源同前缀、可公网访问**。
3. **状态机**：`web_login:{login_token}` → `{group_id, openid, display_name, scope(game|props), target, mode(login|reset), stage, pending_passcode_hash?, code(4 位), attempts, locked_until, exp, consumed}`；`stage: need_register → need_login → code → confirmed`；`GET /auth/web/status` 同时返回「是否已确认」（页面刷新可判定登录态）。
4. **确认与换票**：`#验证码#NNNN` 命中且 openid 一致 → 置 `confirmed`；页面轮询到 confirmed 后调 `GET /auth/web/confirm` **一次性**换取 8h token（`game:{room_id}` 或 `props_admin:all`），随即 `consumed=true` 并销毁短效会话（防止已确认链接被二次使用）。已 consumed 的链接再访问返回 `used`：若浏览器已有有效 Cookie 直接进 `target`，否则提示回群重取。
5. **注册/登录生效时机（R1）**：注册码输入后仅暂存（hash），**群内确认成功后才落库/更新**；确认失败或会话过期则丢弃。于是「错链的人」注册不会污染目标账号，其本人用自己链接重新注册即可。
6. **验证码语义（R2）**：4 位码必须与**回复人 openid** 比对——这就是「本次登录/注册的有效性」判定；不匹配只回「这个验证码不是你的，请用你自己的链接」+ 给回复人重签一条新链接，绝不泄露码归属者身份。
7. **页面交互（`apps/web` `/login`，公开同源）**：① 顶部显示群昵称 + 开局信息（房间/人数/阶段/武将包）；② 未注册 → 注册表单（两个输入框，前端校验 6 位 `[0-9a-zA-Z]` 且一致）；已注册 → 输入注册码；③ 成功后反显随机 4 位数字 + 「一键复制 `@机器人 #验证码#NNNN`」（`navigator.clipboard` 失败降级 `select()`）；④ 进入码视图即开始状态轮询（1.5–2s，长轮询 20s 兜底）；⑤ 已确认 → 显示 **2 秒过渡提示**（「已验证，正在进入…」）→ 跳 `target`；⑥ 已登录（有效 Cookie）→ 直接跳 `target`，不再走码流程。
8. **群侧命令**：① `#验证码#NNNN`（兼容 `#验证码 0000`）**先于一切路由**、任意玩家可用；② `#网页` 重取本人链接（scope 随当前上下文：有对局 → 该局，无对局 → 提示）；③ `#中台` 先校验白名单（非白名单直接回「无权限」）→ 回中台登录链接；④ `#重置注册码`：复用同一流程（mode=reset），群内确认后**不跳转**，页面只提示「已重置」；⑤ 开局/开始回执列出**所有非机器人玩家**的登录页链接（每人一行；8 人局 ~700–800 字，超限则拆两条被动回复）。
9. **中台（要求 6 + Q4 同源公网）**：构建后 `/props-admin` 由 web **同源托管并公网可达**，准入=登录会话 + `PROPS_ADMIN_WHITELIST`（默认回落 `DEV_WHITELIST`）；`/internal/gameprops/*` 只允许经 web 代理且需会话（不再直接暴露给浏览器）；`PROPS_ADMIN_TOKEN` 降为本机应急开关。**P1「中台不挂公网」边界据此改写**：`check:props-boundary` 从「未挂载」改为「仅白名单准入 + 内部 API 不可直连 + 无静态数据泄露」。
10. **失败与锁定**：注册码错误 **3 次锁 30 分钟**（按 `(group_id, openid)`），统一错误文案（不区分「未注册/密码错」）；验证码错误不计入注册码锁定（但记录日志）；所有会话接口 `Cache-Control: no-store`。
11. **昵称保证（Q7）**：昵称来源 = 该玩家最近一次 @ 消息的 `author.username`，在 `#加入`/任意命令时刷新 `names:{group_id}` 缓存；为空时回退 openid 前 8 位并打 `[auth][warn] nickname_missing`（不阻塞流程）；签发链接时写入会话记录，避免页面再查。
12. **P7 同步（最高优先级降低）**：菜单顺序 **三国杀 1 / 拉斯维加斯 2 / 猜拳 3**；三国杀仅被动播报（`#局面` = 一行「第 N 轮 · X 的 <阶段>（等待 Y）· 存活 k/n」+ 链接），动作类命令一律拒绝并引导 Web；关闭三国杀 LLM 叙述；`#加机器人`/`#单人` 在 sgs 拒绝（机器人推进归 P6）。
13. **文档/决策**：新增 `ADR-0031-web-cross-device-auth.md`（放弃扫码的依据、跨端确认模型、token/code 同生命周期、一次性换票、中台公网化与白名单、P1 边界变更）；更新 `docs/modules/auth.md`、`web.md`、`props-admin.md`、`agent-gateway.md`、`docs/games/sanguosha/development-plan.md`、`external-constraints.md`（QQ 侧约束 + 自建流程 10min/20s/3 次/30min 数值，来源=本项目设计、状态=待实测）。
