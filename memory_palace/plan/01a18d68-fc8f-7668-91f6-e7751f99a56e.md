# 计划文档

## 计划

1. 【本期范围】P4.4.0 数据/开关（必交）＋ P4.4.1 第一批：风包 8 将（魏延/夏侯渊/曹仁/小乔/黄忠/周泰/于吉/张角）＋ 其所需机制底座。一将成名/界限突破（P4.4.2）与其余批次留后续会话，不在本期改同包其余武将。
2. 【包登记】`apps/scripts/gen-sanguosha-engine-data.mjs` 的 `GENERAL_PACKS` 增 `wind_fire_forest_mountain`（gids 取 heroes.json 该 pack 全部 48 位：27-30/34-57/61/100/210-212/362/400-415；femaleGids {30,46,57,411}；按 gid 升序）；`DEFAULT_GENERAL_PACKS = ["standard","wind_fire_forest_mountain"]`，data.rs 新增 `WIND_FIRE_FOREST_MOUNTAIN_GENERALS/_COUNT`、`GENERAL_PACK_KEYS`、`general_codes_in_packs()`；`--check` 同口径逐字节比对。16 位后续/SP 武将随包登记（技能未实现→不进池，见选将池口径）。
3. 【Config】`state::Config` 增 `general_packs: Vec<String>`（`serde(default = "default_general_packs")` = `["standard"]`，旧快照自动补齐不改变已有对局）＋ `general_packs_mode()`；新增 `parse_general_packs(mode)`：`+` 分隔、去重、按 `GENERAL_PACK_KEYS` 归一化、未知/空包报错；不做「必须含 standard」的强制（由 lobby 只暴露两种组合来约束）。
4. 【选将池】`data::general_codes_in_packs(packs)` 按 `GeneralDef.pack` 过滤；`lib::offer_to_lord` 与 `distribute_offers_to_others` 改用该函数（不再写死 `STANDARD_GENERALS`），主公候选 = 启用包内全部主公将 + N 名非主公；池子准入再加 `skills::general_ready(code)`（技能注册表存在且全部 `implemented:true`），未实现武将不进候选（避免白板将进局）。
5. 【lobby】新增动作 `lobby:set_general_packs:standard` / `lobby:set_general_packs:standard+wind_fire_forest_mountain`（描述带启用包与「当前可用武将数」），仅 host/未开局可改；execute 分支写 `config.general_packs`；沿用现有「已开局不能修改房间」拦截。视图 `config` 自动透出 `general_packs`（`view_contract` 的 config 为整体字段，无需改键表；同步 `apps/web` 的 `SgsConfig` 类型为 `unknown`/显式字段）。
6. 【技能注册表】风包 8 将技能逐将注册并实现：魏延（狂骨/奇谋）、夏侯渊（神速）、曹仁（据守/解围）、小乔（红颜/天香）、黄忠（烈弓）、周泰（不屈/奋激）、于吉（蛊惑）、张角（鬼道/黄天/雷击）；`skills_of` 增分支，未实现的同包武将不注册（`skills_of` 返回 `&[]`，天然不触发、不进池）。
7. 【机制底座（按风包裁剪）】① 武将牌标记区 `Seat.marks: BTreeMap<String, Vec<String>>`（不屈「创」/后续「田/橘/任/荣/化身」通用），个人视图下发；② `Seat.flipped` 翻面 + 回合跳过/翻回语义（曹仁据守/解围、后续放逐/悲歌）；③ 限定技已用标记沿用 `Seat.flags`（奇谋/涅槃）；④ 伤害防止/替代窗口（天香）复用 `damage_before` 思路，新增 `prevent_damage` 出口；⑤ 判定改判复用 `judge_rewrite`（鬼道=任意黑色牌替换，与鬼才同帧）；⑥ 转化技复用 `virtual_defs`/`effective_def_code`（红颜=黑桃当红桃的花色视图、蛊惑扣置转化）；⑦「视为装备」/废除装备栏/额外回合等火·山·SP 包机制**不提前做**。
8. 【风包逐将口径】每将 ≥3 条规则用例（`tests/p67.rs` 起按批分文件）+ 跨技能交互：鬼道×雷击、红颜×天香、不屈×奋激、据守×翻面×解围、奇谋×出杀次数/距离、神速×杀次数。默认「可以发动」技能按现有惯例优先 `choice` 询问，锁定技自动；确有歧义者落 `rules-rulings.md`。
9. 【文档】`development-plan.md` 更新 P4.4.0/4.1 实施记录与下一步；`skills.md` 注册表/钩子表/测试计数；`data-model.md` §3.7（生成口径：默认两包、`general_packs`）与 §4（`Seat.marks/flipped`、`Config.general_packs`）；`data/README.md` 生成命令；`memory_palace/milestones.md` 记 M24；新增 ADR-0023「T4 技能机制扩展（标记区/翻面/限定/伤害防止/转化）」。
10. 【后续批次（不在本期执行，仅登记）】P4.4.1-火（典韦/荀彧/庞统/卧龙/太史慈/庞德/颜良文丑/袁绍，需拼点/觉醒?/视为装备/多目标杀）→ 林（徐晃/曹丕/孙坚/董卓/祝融/孟获/贾诩/鲁肃，需翻面/南蛮归属/限定技）→ 山（张郃/邓艾/姜维/刘禅/孙策/张昭张纮/左慈/蔡文姬，需觉醒/标记/额外回合/化身）→ 16 位后续/SP（转换技/废除装备栏/牌堆底）。P4.4.2 一将成名/界限突破需先定同名替换口径（ADR-0024）。
