# 计划文档

## 计划

1. 【目标】新增独立 MCP 服务 docs-mcp（Rust stdio），提供「本地开发文档预览」只读原语；QQ 命令 #文档（无参数）→ docs-mcp 校验白名单 → 网关签发一枚覆盖全部根（docs:all）的短链 → web 展示文件树 + 文件内容。
2. 【配置集中一处】新增 config/dev-docs.json：roots（4 根，可配）+ exclude（排除目录，可配），默认 roots=docs / memory_palace / .pi/prompts / .pi/skills，默认 exclude=memory_palace/artifacts；由 docs-mcp 与 server 共读（读取模块放 crates/shared），路径可用 DOCS_CONFIG 覆盖。
3. 【原语（crates/docs-mcp）】prepare_docs_link(qq_id)（只读、无 root 参数）：DEV_WHITELIST 校验 → 返回 {resource:"docs:all", roots:[...]}；list_capabilities() 自述能力（含 usage/example）。搜索功能本期不做，在 docs-mcp 内备注 TODO。
4. 【server 资源 API】新增 crates/server/src/docs_routes.rs：GET /resources/docs/tree?token= → 返回各根子树 JSON；GET /resources/docs/file?token=&root=&path= → 返回 .md 内容。token 校验 + docs: 前缀；root 白名单（来自配置）；路径规范化+前缀校验防穿越；仅 .md 可读；exclude 目录过滤。
5. 【web】新增 GET /dev_docs（树页）与 GET /dev_docs/file（内容页）：树用原生 <details>/<summary> 折叠（零 JS）；.md 用相对 <a> 链接可点，非 .md 仅显示名称不可导航；.md 走 marked 渲染，其余仅文本。
6. 【agent-gateway】新增 docs-client.ts（stdio → docs-mcp）；命令 #文档（无参数）→ prepareDocsLink → 签发 token → 被动回复链接；接入 main() connect；dev-command 解析 + 测试。
7. 【安全基线】全程只读；root 固定白名单；exclude 目录过滤；拒绝 .. / 绝对路径 / symlink 逃逸；非 .md 不可预览；token 绑定 docs:all，越权 403；不做写/上传/删除。
8. 【文档】新增 docs/modules/docs-mcp.md；更新 docs/modules/web.md、docs/conventions/mcp-primitives.md（第 3 个服务能力）、docs/dev-environment.md（MCP 表/环境变量）、docs/architecture.md（模块拓扑）；重大决策记 ADR（拟 ADR-0005）。
9. 【工作量】预估 ~3.5–4 人日（docs-mcp 0.75 / server 1 / web 0.5 / gateway 0.5 / 共享配置 0.25 / 文档+联调 0.5）；难度中低；主要风险=路径穿越与排除目录边界。
10. 【范围外】搜索（docs-mcp 内备注 TODO）、编辑、上传、语法高亮、crates/apps 源码、Git diff。
11. 【后续扩展】大文件/敏感目录一律用 config 的 exclude 处理（不实现独立大小上限）；搜索能力留 docs-mcp 内 TODO。
