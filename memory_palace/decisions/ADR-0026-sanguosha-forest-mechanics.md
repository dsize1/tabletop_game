# ADR-0026：三国杀 P4.4.1 林包机制（行殇 / 南蛮归属 / 摸牌替代 / 交换手牌）

- **状态**：已采纳（2026-10-30，P4.4.1 林包批次落地）
- **关联**：ADR-0016（规则在代码）、ADR-0023（标记/翻面）、ADR-0025（拼点）、`skills.md` §2.3、`development-plan.md` P4.4
- **影响范围**：`crates/engines/sanguosha`（`resolve_forest.rs`、死亡清理、南蛮结算、摸牌阶段、目标过滤）

## 1. 背景

林包 8 将需要一批跨阶段机制：

| 机制 | 使用者 | 缺口 |
|---|---|---|
| 死亡时接管死者所有牌 | 曹丕·行殇 | 死亡清理先弃牌，无法拦截 |
| 南蛮免疫/伤害来源/获得 | 祝融·巨象、孟获·祸首 | 南蛮结算固定用使用者为来源、正常弃牌 |
| 摸牌阶段替代 | 孟获·再起、鲁肃·好施 | 摸牌阶段只有固定 2 张 |
| 体力上限减少 | 董卓·崩坏 | 无 max_hp 减少/选项帧 |
| 黑色锦囊目标过滤 | 贾诩·帷幕 | 目标枚举不考虑牌色 |
| 翻面+摸牌 | 曹丕·放逐 | 翻面已有，缺「受伤后选目标」帧 |
| 受伤后拼点夺牌 | 祝融·烈刃 | 拼点可复用，缺父帧 outcome 保护 |
| 限定技多角色顺序选择 | 贾诩·乱武 | 无多角色迭代帧 |
| 交换手牌 | 鲁肃·缔盟 | 无交换/费用帧 |

## 2. 决策

1. **行殇**：`death()` 在标记牌清理后、身份/奖惩前判断是否终局；非终局且有存活「行殇」持有者时，**保留死者手牌/装备/判定区**并压入 `XingshangFrame`（询问获得或放弃）；否则按原逻辑弃置。终局不触发（避免 `resolution` 清空丢牌）。
2. **南蛮**：`trick_targets` 过滤 `nanman_immune`（巨象/祸首）；结算伤害来源替换为存活「祸首」持有者（其他角色使用南蛮时）；`trick_done` 时存活「巨象」持有者获得该牌（与是否被无懈无关）。
3. **再起**：摸牌阶段可选；亮出 `X = 已损失体力` 张牌（上限按牌堆），红桃数回复体力（不超过上限），获得全部亮出牌并跳过摸牌。
4. **好施**：摸牌阶段可选，正常摸 2 后再多摸 2；若手牌 >5，选 `floor(手牌/2)` 张交给手牌最少的其他角色（`MultiSelect` → 目标）；手牌不足 1 张时按 0 处理。
5. **崩坏**：结束阶段锁定，若存在体力低于自己的存活角色（即自己不是最低），必须在「失 1 体力 / 减 1 体力上限」中二选一；上限最低为 1，体力按新上限截断。
6. **帷幕**：目标枚举阶段过滤黑色锦囊牌（物理牌花色黑色），覆盖单体/AOE/借刀/延时；不改变牌本身。
7. **放逐**：受伤后（存活）可选一名其他角色，翻面 + 摸 `min(已损失体力,5)` 张。
8. **烈刃**：使用【杀】造成伤害后（目标存活）可与目标拼点；赢则从其手牌/装备/判定区获得一张牌。`LiewenFrame` **保存父帧 outcome**（如【杀】的响应结果）并在结束时恢复，避免拼点覆盖。
9. **乱武（限定）**：其他角色按左手侧顺序依次二选一；有【杀】时可对最近角色使用（自动取第一张【杀】，简化），否则失去 1 体力。每步压栈结算，死亡者跳过。
10. **缔盟**：出牌阶段限一次；选两名其他角色，弃 `X = |手牌差|` 张后交换其手牌；X=0 直接交换。
11. **完杀**：贾诩回合内，除贾诩本人与濒死者本人外，其他角色不能使用【桃】（含急救/蛊惑当桃）。
12. **酒池/肉林/截辎/颂威/暴虐**：酒池黑桃手牌当【酒】（含濒死自救）；肉林使涉及董卓与女性的【杀】需 2 张【闪】；截辎在其他角色跳过摸牌阶段后摸 1；颂威在魏势力黑色判定生效后令主公曹丕摸 1（自动）；暴虐在其他群势力造成伤害后令董卓判定，黑桃回复 1。

## 3. 已知边界

- 行殇终局不触发（防止终局清栈丢牌）；死者的武将牌标记不参与行殇，始终弃置。
- 巨象获得南蛮时若手牌超上限按持有上限弃置。
- 乱武的【杀】自动取第一张、自动选择最近目标（不逐张选牌/目标）；不触发铁骑/雌雄等「目标指定后」窗口（仅走基础【闪】响应）。
- 好施必须先选牌再选目标；手牌数在选牌时计算。
- 烈刃的拼点牌与父帧 outcome 隔离，父帧（【杀】）必须仍能继续结算。
- 帷幕只过滤「目标枚举」，不阻止已经进入结算的牌（如已指定后变化）。
