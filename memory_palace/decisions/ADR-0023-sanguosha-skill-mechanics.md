# ADR-0023：三国杀 P4.4 技能机制扩展（标记区 / 翻面 / 天香 / 蛊惑）

- **状态**：已采纳（2026-10-30，随 P4.4.1 风包批次落地）
- **关联**：ADR-0016（规则在代码、中台只读）、ADR-0022（装备技能化）、`docs/games/sanguosha/skills.md`、`development-plan.md` P4.4
- **影响范围**：`crates/engines/sanguosha`（`Seat.marks/flipped`、`resolve_wind.rs`、`resolve.rs` 窗口）、视图契约（`marks/flipped`）

## 1. 背景

P4.4.1 风包 8 将需要的机制超出 P4.1–P4.3 的「手牌/装备/判定区 + 结算栈」：

| 机制 | 首批使用者 | 原引擎缺口 |
|---|---|---|
| 武将牌上的标记（「创」） | 周泰·不屈 | 无公共「武将牌上」区域；牌数守恒未统计 |
| 翻面（背面朝上，跳过回合） | 曹仁·据守、夏侯渊·神速③ | 无 `Seat.flipped`，无回合跳过/翻回语义 |
| 受到伤害时防止/转移 | 小乔·天香 | `apply_damage` 直接扣血，无防伤害窗口 |
| 扣置手牌当任意牌 + 质疑 | 于吉·蛊惑 | 无隐藏扣置、无多人质疑窗口、"真假"判定 |
| 判定改判扩展 | 张角·鬼道 | 改判窗口只登记鬼才；只允许任意手牌 |
| 视为使用【杀】 | 夏侯渊·神速 | 【杀】帧必须有物理牌、必须计次数 |
| 出牌阶段外主动/触发 | 黄天、奋激、雷击 | 钩子分散，需要集中触发点 |

## 2. 决策

1. **标记区**：`Seat.marks: BTreeMap<String, Vec<card_id>>`（标记 code → 牌实例，按获得顺序）。牌实例离开原区域进入标记区；`death` 时清空并进弃牌堆；`CardCounts` 增加 `marks`，牌数守恒覆盖标记区；公共视图 `seats[].marks` + 个人区 `marks` 下发。
2. **翻面**：`Seat.flipped: bool`。准备阶段若 `flipped`：翻回正面、记 `skip_turn`、结束本回合（可先触发解围）；`end_turn` 正常推进。神速③在准备阶段直接置 `flipped=true` 并跳过弃牌阶段。
3. **伤害防止窗口**：`apply_damage` 拆为 `apply_damage`（允许天香窗口）/`apply_damage_now`（跳过）。天香以 `Frame::Tianxiang`（Ask → 弃红桃手牌 → 目标 → 二选一）实现；选项 1 的伤害类型记为普通，X 取目标受伤后的已损失体力（上限 5）。
4. **蛊惑**：`Frame::Guhuo`（Declare → Question → Resolve）。物理牌留在手牌直到结算/作废；按「其他存活、未缠怨」的顺序逐一询问质疑；有质疑则展示并比对声明：
   - 真：质疑者获得 `Seat.flags["chanyuan"]`，牌按声明继续结算；
   - 假：牌作废（弃置），无效果；响应窗口保留，可继续用其他牌响应；
   - 无人质疑：直接按声明结算（真假不影响）。
   每回合每名角色限一次（`turn_counters["guhuo_used_<seat>"]`）。
   缠怨：不能质疑于吉；体力值为 1 时不能使用或打出手牌（出牌/响应/濒死/无懈选项统一过滤；装备技能与八卦阵不受影响）。
5. **改判窗口扩展**：`rewrite_order/options` 支持鬼道（黑色手牌）；鬼道与鬼才同一 `judge_rewrite` 帧，按座位顺序询问；本轮仍只支持手牌（装备区牌改判留后续）。
6. **虚拟【杀】**：`ShaFrame` 增 `no_distance` / `virtual_card`；神速直接压入空 `card` 的 Sha 帧，绕过 distance 过滤、不计 `sha_used`；`discard_from_processing` 对空 id 安全 no-op。
7. **技能触发点集中**：
   - `apply_damage` 末尾：狂骨（来源距离 ≤1）。
   - `turn::phase_step`：神速（Prepare）、据守（End）、解围（翻回正面）。
   - `finish_respond_play` / `finish_respond_dodge`：雷击（使用/打出【闪】）。
   - `act_pick` / `act_discard`：奋激（手牌被获得/弃置）。
   - `act_target`：烈弓（目标不能【闪】）。
   - 判定 `QuickJudge.reason = leiji`：黑桃 2 点雷电、梅花回复 1 并 1 点雷电。

## 3. 已知边界（后续批次处理）

- 鬼道/鬼才改判只支持手牌，暂不支持装备区黑色牌。
- 解围「移动场上一张牌」当前只能移动到自己的对应装备槽/判定区，不支持移动到其他角色区域。
- 奋激触发点覆盖 `过河拆桥/顺手牵羊/反馈/弃牌帧`，未覆盖所有「获得手牌」路径（如后续技能转移牌）。
- 神速②的「弃置一张装备牌」只支持手牌中的装备牌，暂不支持已装备的牌。
- 不屈在牌堆不可用时按无法发动处理（保持牌数守恒）。
