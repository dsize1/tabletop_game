# ADR-0027：三国杀 P4.4.1 山包机制（觉醒 / 化身 / 巧变 / 固政）

- **状态**：已采纳（2026-10-30，P4.4.1 山包批次落地）
- **关联**：ADR-0016、ADR-0023（标记/翻面）、ADR-0025（拼点）、ADR-0026（林包）、`skills.md` §2.4
- **影响范围**：`crates/engines/sanguosha`（`resolve_mountain.rs`、`Seat.extra_skills/huashen`、`SgsState.extra_turn/phase_discarded`、死亡/摸牌/阶段机）

## 1. 背景

山包 8 将需要「技能获得」「额外回合」「阶段跳过」等跨回合机制：

| 机制 | 使用者 | 缺口 |
|---|---|---|
| 觉醒技授予技能 | 邓艾/姜维/孙策/刘禅 | `has()` 只看武将原始技能 |
| 回合外失去牌判定 + 距离 | 邓艾·屯田 | 无失去牌钩子；距离无「田」修正 |
| 阶段跳过 + 效果 | 张郃·巧变 | 无准备阶段多选阶段帧 |
| 目标指定后反制 | 刘禅·享乐 | 无「使用者弃基本牌否则杀无效」帧 |
| 额外回合 | 刘禅·放权 | 回合推进无插入额外回合 |
| 拼点夺牌 + 拒绝 | 孙策·制霸 | 拼点结果不带牌 id；无拒绝窗口 |
| 弃牌阶段回收 | 张昭张纮·固政 | 无「本阶段弃置牌」记录 |
| 化身/技能获得 | 左慈 | 无化身牌与动态技能列表 |
| 伤害后判定 | 蔡文姬·悲歌 | 无「杀伤害后弃牌判定」帧 |
| 死亡失去技能 | 蔡文姬·断肠 | `has()` 无技能失效标记 |

## 2. 决策

1. **额外技能**：`Seat.extra_skills: Vec<code>`；`skills::has` 先查 `skills_lost`（断肠），再查额外技能，最后查武将原始技能。`skills::grant_skill/revoke_skill` 管理；`def_of(code)` 支持视图展示；`first_implemented_skill` 供化身。
2. **觉醒**：准备阶段 `awaken_triggers` 自动判定：
   - 凿险（田≥3）：减 1 上限，授予 `jixi`；
   - 志继（无手牌）：`AwakenFrame` 二选一（回复 1 / 摸 2），减 1 上限，授予 `guanxing`；
   - 魂姿（体力=1）：减 1 上限，授予 `yingzi` + `yinghun`；
   - 若愚（主公且体力最小）：增 1 上限、回复 1，授予 `jijiang`。
   已觉醒写入 `flags["awaken_*"]`，不重复触发。
3. **屯田**：`turn::take_card` 与 `resolve::act_pick` 在回合外失去牌后压 `QuickJudge(reason=tuotian)`；非红桃判定牌留处理区并置于 `marks["tian"]`；每张「田」使距离 -1（`tuotian_bonus` 同时进入攻击范围与锦囊距离）。
4. **巧变**：准备阶段一次；弃 1 手牌后选择跳过判定/摸牌/出牌/弃牌：
   - 跳过判定/弃牌：`qiaobian_skip_judge/discard` 计数；
   - 跳过摸牌：`skip_draw` + `QiaobianFrame(remaining=2)` 逐名获得手牌（可随时停止）；
   - 跳过出牌：`skip_play` + 复用解围的「移动场牌到自己区域」帧。
5. **享乐**：成为【杀】目标后压 `XiangleFrame`；使用者可弃 1 张基本牌（`MultiSelect`）使【杀】继续，否则【杀】无效（弃置处理区并结束本次杀）。
6. **放权**：出牌阶段主动发动 → 跳过出牌阶段并置 `fangquan_pending`；结束阶段压 `FangquanFrame` 选目标，弃 1 手牌（简化自动取第一张）后设置 `SgsState.extra_turn`；`end_turn` 优先插入该额外回合。
7. **激昂**：使用/成为红色【杀】或【决斗】目标后自动摸 1（`jiang_trigger`）。
8. **制霸**：其他吴势力出牌阶段限一次；孙策未觉醒（魂姿）时直接拼点，已觉醒时先由孙策选择接受/拒绝；挑战者没赢则孙策从弃牌堆获得两张拼点牌。`Outcome::Pindian` 增加双方拼点牌 id。
9. **直谏**：将装备手牌置入其他角色对应装备槽（原装备弃置并触发枭姬），然后摸 1。
10. **固政**：`SgsState.phase_discarded` 记录弃牌阶段实际弃置的牌；其他角色弃牌阶段结束时（`GuzhengFrame`）可选择：弃牌者获得一张、固政持有者获得剩余；一律置 `turn_phase=End`，避免回到弃牌阶段重复弃牌。
11. **化身/新生**：`Seat.huashen/huashen_active` 存武将 code；开局随机两张已实现武将牌，展示第一张并授予其第一个已实现技能；准备/结束阶段可替换（`HuashenFrame`），撤销旧技能并授予新技能。新生：受伤后随机加入一张未拥有的化身牌。
12. **悲歌**：角色受到【杀】伤害后（非致命），蔡文姬可弃 1 手牌压 `QuickJudge(reason=beige)`：红桃回复 1、方片摸 2、梅花来源弃 2、黑桃来源翻面。
13. **断肠**：蔡文姬死亡时，杀死她的角色写 `flags["skills_lost"]`，`has()` 恒 false（装备技能仍按装备判定，不受影响）。

## 3. 已知边界

- 放权的主牌弃置为自动取第一张（未开放逐张选择）；额外回合后按目标座位的正常顺序继续。
- 巧变「至多两名角色各一张手牌」逐名选择后可直接停止；跳过出牌阶段的移动复用「解围」移动帧（只能移到自己区域）。
- 化身只获得展示武将的第一个已实现技能；准备/结束各一次替换；新生获得的化身牌需下一次替换才生效。
- 固政的「哪张给弃牌者、剩余归自己」按弃牌列表顺序自动分配（未开放逐张选择）。
- 悲歌只支持弃手牌（不支持装备区），且致命伤害不触发（引擎通用伤害后触发口径）。
- 制霸拒绝窗口仅在孙策已发动魂姿时出现；拼点牌从弃牌堆取回。
