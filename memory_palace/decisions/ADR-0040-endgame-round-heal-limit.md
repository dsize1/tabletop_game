# ADR-0040：终局房规（第 100 轮后【桃】/【桃园结义】回血无效）

- **状态**：Accepted（2026-11-11，用户裁定「增加终局设定」；`rules-rulings.md §45`）
- **相关**：`docs/games/sanguosha/rules.md §13`、`docs/games/sanguosha/ai.md`（自对弈门禁）、
  `check:sgs2-ai`
- **结论一句话**：`round > 100` 起【桃】【桃园结义】**仍可使用但回血无效**；濒死救援不受限。
  这是房规（非官方规则），目的是让 AI 自对弈的长期僵局有确定性收束。

## 背景（为什么要动规则层）

`npm run check:sgs2` 的唯一红项是 `check:sgs2-ai`：`seed=3` 第 0 局跑约 1.4 万步未终局
（历史决策日志 `data/dlog3.jsonl`：step 6000 时已是 **round=179**，两名角色已死、剩余三人
血量在 2–5 之间反复，互不致死），无 illegal，最后被「同一交互态重复 13 次」的环检测中断。

- 本质是**僵局**，不是引擎卡死：双方都能回血/摸牌，谁也打不死谁；
- 门禁的环签名只看 `turn/phase/pending/hp/手牌数`（不含 `round`），分不清「长局」与「死循环」；
- 三个候选口径：①规则层「回合上限=平局」②提高 AI 进攻性 ③门禁区分长局/卡死。

## 决策

用户选**规则层终局设定**（对真人与 AI 一致生效），而不是改 AI 或松门禁：

1. **判定**：`kernel::ENDGAME_ROUND = 100`；唯一入口 `Game::endgame_no_heal()`（`round > ENDGAME_ROUND`）。
   禁止在内核/技能里各写 `round` 比较（沿用「单出口」约定）。
2. **生效范围**：只限【桃】与【桃园结义】的回血（`Effect::Tao` / `Effect::PeachGarden` 跳过 `flow::heal`
   并写日志）。**其它回血源不动**（青囊/仁德/白银狮子/兴衰/救援/遗计…）。
3. **语义**：牌**仍可正常使用/结算/被无懈**（用户原话「使用后无效」），不从合法集移除；
   AI 终局后对这两张牌不再打正分（避免空耗手牌）。
4. **濒死不受限**：【桃】/【酒】/急救/酒池/兴衰等救援照旧（濒死流程本就走 `flow::step_dying`，
   不经过 `Effect::Tao`）。
5. **端侧**：视图根级 `endgame = { no_heal, round, since }`；版图页显示「终局·回血无效」徽标；
   `view_contract` 的 `ROOT_KEYS` 同步登记（新增视图字段=一次契约评审）。

## 被否方案

| 方案 | 否决原因 |
|---|---|
| ① 回合上限=平局 | 官方规则无平局；会改变生产局胜负语义（真人局也判和），影响面比只限两张牌大 |
| ② 提高 AI 进攻性 | 不保证收敛（179→80 回合仍可能不终局）；且是**掩盖僵局**，不是修引擎 |
| ③ 门禁区分长局/卡死 | 只改 harness 判据 = 松门禁；可作补充（`round` 进环签名），但不能替代「对局能结束」这个硬指标 |

## 后果

- `check:sgs2` 全链转绿：`seed=3` 由 9/10 终局 → **30/30 终局**（seeds 1,2,3；loops/stalled 0，10794 步）；
- 生产局超过 100 轮时，第 101 轮起只能靠濒死救援续命 → 对局必然收束到有人死亡；
- 需要长期观察的后续项：若将来出现「靠濒死反复救起」的新僵局，再评估是否扩展限制（需重新裁定）。
