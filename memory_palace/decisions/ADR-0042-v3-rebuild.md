# ADR-0042：废弃 v2 引擎，启动 V3 重构

- **日期**：2026-11-12
- **状态**：**已裁定（用户）**
- **决策**：`crates/engines/sanguosha2`（v2）**不再作为主线继续修补**，改用 V3 重构；
  v2 保留在仓库中作为参考实现，直到 V3 通过验收再删除。

## 背景：为什么放弃 v2

v2 在 2026-11-10 接管正式引擎（v1 crate 删除）后，**2 天真机**暴露 7 类缺陷：

| # | 类别 | 具体缺陷 | 性质 |
|---|---|---|---|
| 1 | 询问口径 | 无匹配牌直接结算（杀/无懈/濒死）——玩家永远没有「假犹豫」窗口 | 迁移丢语义 |
| 2 | 承诺步骤 | 选了「弃置」仍可放弃（御策/峻刑） | 出口语义错 |
| 3 | 状态语义 | 删掉 `Seat.alive`，用 `hp <= 0` 冒充死亡 → 未开局/濒死公开身份 | 状态模型缺字段 |
| 4 | 帧数据 | `need_at` 写 `stack.last_mut()` → 覆盖濒死帧 → 僵尸座位、对局不结束 | 帧数据归属 |
| 5 | 事件归属 | 屯田/燕语在「他人失去牌」时触发（奋激同源） | handler 缺守卫 |
| 6 | 生命周期 | 终局后群活跃登记不解除（`#开局` 仍要求 `#中断`），修了两次 | 跨进程事实源 |
| 7 | 迁移漏项 | 丈八蛇矛未实现、激将主动形态缺失 | 迁移清单不完整 |

期间 `fix(sgs2)` 提交 **16 个**；而系统审计只覆盖「14 个牌移动事件订阅者 + 3 条交互路径 + 视图/身份」，
**296 个技能 × (归属守卫 / 出口语义 / 事件主体) 基本未审** → 沉默风险不可接受。

## 根因（过程，而非单纯能力）

1. 删除 v1 前**没有把 v1 代码注释里的裁定与交互口径抽成规范**（「有手牌必须询问」「无牌才跳过」等）；
2. 修复方式是「真机报一个修一个」，先修后审计；
3. 门禁只查形状（字段集 / 文案重复 / legal≡execute），不查语义（询问是否发生、事件主体对不对）。

## 后果

- v2 冻结功能开发；V3 启动计划见 `memory_palace/plan/next-v3-rebuild.md`；
- V3 必须继承 v2 的**规格层与契约门禁**（spec-kit、775 条锚点、296 技能注册表、789 条用例中的口径用例）；
- V3 的验收标准包含 **与 v1 行为对拍**（v1 可从 git `f8a7db3^` 复活为 test-only oracle）。
