# ADR-0025：三国杀 P4.4.1 火包机制（拼点 / 视为装备 / 涅槃 / 天义）

- **状态**：已采纳（2026-10-30，P4.4.1 火包批次落地）
- **关联**：ADR-0016（规则在代码）、ADR-0023（标记/翻面/天香/蛊惑）、`docs/games/sanguosha/skills.md` §2.2、`development-plan.md` P4.4
- **影响范围**：`crates/engines/sanguosha`（`resolve_fire.rs` 新增、拼点帧、八阵虚拟装备、天义多目标）

## 1. 背景

火包 8 将引入 P4.4.1 的第一批新机制：

| 机制 | 使用者 | 缺口 |
|---|---|---|
| 拼点 | 荀彧·驱虎、太史慈·天义 | 无通用「双方各选一张手牌比点数」帧 |
| 视为装备 | 卧龙·八阵 | `has_equipment_skill` 只看实际装备槽 |
| 限定自救 | 庞统·涅槃 | 无「弃置所有区域 + 复原武将牌 + 回复至 3」流程 |
| 无距离/多目标【杀】 | 太史慈·天义 | `ShaFrame` 只有方天画戟多目标、无「无距离」组合 |
| 目标指定后弃牌 | 庞德·鞬出 | 无「弃目标一张牌，装备/非装备分支」窗口 |
| 摸牌替代 + 颜色转化 | 颜良文丑·双雄 | 无「判定获得 → 本回合异色当决斗」 |
| 主公技手牌上限 | 袁绍·血裔 | 手牌上限只由体力/克己决定 |

## 2. 决策

1. **通用拼点帧** `PindianFrame`：发起者与目标各选一张手牌（`choice` pending）→ 同时亮出 → 比较点数（A=1…K=13；**同点视为发起者未赢**）→ `Outcome::Pindian { winner: Option<seat> }` 回传父帧；拼点牌进弃牌堆。父技能帧（驱虎/天义）压在下层，通过 `outcome` 读取结果继续。
2. **视为装备** `skills::virtual_equip`：卧龙·八阵在**防具槽为空**时视为装备【八卦阵】；`has_equipment_skill` / `triggered` / 响应选项 / `equipment_skills` 视图统一消费；有实际防具时八阵不生效；青釭剑 `ignore_armor` 可无视。
3. **涅槃（限定）**：濒死时仅濒死者本人可发动；弃置手牌/装备/判定区/武将牌标记 → 全部进弃牌堆；翻回正面；体力回复至 `min(3, max_hp)`；摸 3 张（受持有上限约束）；保留已用限定技/觉醒等 `flags`，不重置。
4. **天义**：拼点赢 → 本回合 `sha_limit +1`、使用【杀】无距离限制、可多指定一个目标（复用 `ShaFrame.pending_targets`，恰好 2 目标顺序结算）；没赢/平手 → 本回合不能使用【杀】（`sha_blocked`，含转化/蛊惑声明）。
5. **鞬出**：使用【杀】指定目标后，若目标有牌可弃：弃装备 → 目标不能【闪】；弃非装备 → 目标获得此【杀】，本次【杀】结束。目标为大乔时流离优先（先流离后不触发鞬出），作为已知边界。
6. **双雄**：摸牌阶段改为判定并获得判定牌（`QuickJudge(reason=shuangxiong)`），记录判定颜色；本回合可将**异色**手牌当【决斗】主动使用（不支持响应）。
7. **血裔（主公技，锁定）**：仅袁绍为主公时生效；其他存活**群**势力角色数 ×2 加到手牌上限。
8. **强袭**：出牌阶段限两次；代价（失 1 体力 / 弃武器）后对「本回合未以此法指定过」的角色造成 1 伤（`turn_counters` 位图记录目标）。

## 3. 已知边界

- 拼点亮牌顺序（发起者先选、目标后选）在引擎侧顺序询问；双方信息在亮牌前互不可见。
- 天义多目标与方天画戟同时存在时分别生成组合，不做叠加（最多 3 目标）；不做 4 目标。
- 鞬出与流离的时序：流离优先，流离后本次【杀】不再触发鞬出。
- 涅槃「复原武将牌」只翻回正面并清除标记；不重置铁索横置、不重置已用限定技/觉醒标记。
- 八阵虚拟装备不产生牌实例，不参与牌数守恒；`equipment_skills` 视图以 `slot=armor / code=bagua_zhen` 下发。
- 驱虎/天义拼点若一方手牌为空则技能不可发动（入口过滤）。
