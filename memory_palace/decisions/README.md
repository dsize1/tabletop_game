# 架构决策记录（ADR）

## 格式

文件名：`ADR-<编号>-<标题>.md`

内容包含：

- **背景**：为什么需要做决策
- **决策**：选择了什么
- **理由**：备选方案与取舍
- **影响**：对项目的影响
