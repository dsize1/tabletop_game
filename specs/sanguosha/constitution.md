# 引擎语义宪法（sanguosha2）

> 本文件是最上位约束。任何实现、门禁、用例与之冲突时，**以本文件为准**；
> 修改宪法需要用户裁定 + ADR。

## I1 询问完整性

**只要「合法动作集」非空，就必须产生 pending 让玩家决定。引擎不得代放弃、代选择、代发动。**

- 无手牌（且无技能/装备替代）→ 合法集为空 → **不询问**（杀直接命中、无懈无人可打、濒死无人可救）；
- **有手牌 → 即使没有对应的牌，也必须显式询问**（选项只有「不出」= `pass`），保留犹豫博弈；
- 规则级「不能响应」（毅重② / 诈降红色【杀】/ 铁骑 no_shan）→ 合法集为空 → 不询问；
- 不可预测的随机（拆/顺手牌）必须走 `Game::rand_below`；固定取「第一张」= 代选；
- 回答缺失 / 陈旧回答 → 标记 `response_stale` 并**重新询问**，不得按「放弃」继续。

判定入口：`Game::must_ask(seat, has_option)`。
门禁：`contracts/interaction.json`（禁止裸 `if !has {` / `if options.is_empty() {` 跳过）。

## I2 状态语义

**存活 / 死亡是显式状态，不由 `hp` 推导。**

- `Seat.alive` 只由 `flow::die`（死亡确认结算）置 `false`；
- 濒死（`hp = 0` 等待救援）**仍是存活**：不公开身份、不判胜负、不跳过其回合；
- 未开局 / 未选武将（`hp` 未初始化）**不是死亡**：视图不展示 `hp / max_hp / alive`；
- 身份公开：仅主公，或 `alive == false` 之后；
- 开局按武将表满血（`max_hp`，主公 +1）。

不变量：`Game::check_no_zombies()`（`alive && hp <= 0` 且不在濒死 → 报错）。
门禁：`contracts/state.json`（禁止 `view.rs` / `identity.rs` 用 hp 推导存活）。

## I3 视图不判业务

**视图是投影，不是判定。** 身份是否公开、是否存活、能否响应，一律由引擎状态决定，
`view.rs` 只做字段投影与裁剪；不得在视图里写业务规则（如 `if hp <= 0 { 公开身份 }`）。

## 硬约束 A：一个语义只能有一个入口

同一语义不得存在两条并存通道（例如「响应前先压接力帧」+「响应窗口里的选项」）。
结果回传只允许**单值结果通道**（`relay_result` / `wuxie_result` / `pindian_result` 这类
「写一次、读一次」的字段），不得用多个全局标志 + `data["…_wait"]` 做状态机协作。

> 事故：2026-11-12 激将双通道 → 「激将」被当成未响应直接结算伤害。

## 硬约束 B：帧数据只能写发起帧

handler 可以压子帧（伤害 → 濒死、技能 → 判定…），但**自己的进度数据只能写回自己的帧**。
禁止 `stack.last_mut()`（栈顶可能是刚压入的子帧）。

> 事故：2026-11-12 `card_play::need_at` 写栈顶 → 牌结算 data 覆盖濒死帧 →
> 濒死读到别人的 victim → 出现「不死不活的座位」、对局永不结束（seed=3 自对弈复现）。

## 例外表（允许「不问」的完整清单）

| 情形 | 依据 | 判定 |
|---|---|---|
| 响应窗口：无手牌且无可替代手段 | I1 | 合法集为空 → 跳过 |
| 响应窗口：规则禁止响应（毅重②/诈降红杀/铁骑） | I1 | 合法集为空 → 跳过 |
| 无懈：无手牌且无转化/装备替代 | I1 | 跳过 |
| 濒死：无手牌且无救援手段 | I1 | 跳过 |
| 拆/顺：目标区域全空 | I1 | 跳过 |
| 强制选择步骤（展示/选牌/弃至上限/取五谷） | I1 | **必须**问；占位出口提交会被拒绝 |
