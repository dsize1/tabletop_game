# P3 Web 真机验收清单（人工）

> 状态：**待人工执行**（P3 收尾）。范围：三国杀 Web 页在真实手机浏览器上的可用性；桌面 Chromium 已由
> `npm run test:sgs-web` 自动覆盖（系统 Edge，四档视口 + 动作提交）。
> 记录结果后：阈值/手势调整回写 `ui-spec.md` §5/§7.3；问题按严重度开修复项。

## 准备

```bash
# 终端 1（前台常驻；server 3000 / web 18080）
npm run dev:up:noqq -- --no-build --no-props --no-decision

# 终端 2（建局 + 签 token + 打印每人链接）
npm run sgs:web-room
```

- 手机与电脑同一局域网时，把链接里的 `127.0.0.1` 换成电脑局域网 IP（或走 Cloudflare Tunnel）；
  若用 Tunnel/反代，先确认 `WEB_BASE` 与访问域名一致。
- 每条链接对应一名玩家，**不要互传**（token 绑定 openid）；token 默认 1h，过期重跑脚本。
- 令牌过期/多人共机场景：重签 token 后刷新页面即可（不做 localStorage）。
