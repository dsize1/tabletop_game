# 三国杀技能注册表与触发钩子（P2.4）

> 状态：**P4.4.1 SP-1 8 将已实现（2026-10-30）**；标准 25 将 + 风/火/林/山/SP-1 共 65 位已实现。标准包全部技能（49 技能 + 5 件装备效果）：鬼才改判窗口、转化（武圣/龙胆/倾国/急救/国色）、锁定/触发（咆哮/马术/英姿/裸衣/天妒/谦逊/连营/枭姬/空城/无双）、主动与伤害后（苦肉/青囊/结姻/反馈/遗计/刚烈）、判定/选择（铁骑/洛神/反间）与流离。用例 **343** 条；门禁 `check:sgs-skill-cases`（65/65 已实现武将每人 ≥3 条）。
> 关联：`generals.md`、`state-machine.md` §2.2（pending）、`legal-actions.md` §4.7、`development-plan.md` P2.4、ADR-0016（技能事件总线）。

## 1. 设计

- 技能按**武将**绑定（`sgs_generals.code`），引擎侧用固定顺序派发：
  **技能声明优先级 → 当前回合玩家左手侧座位顺序 → 注册顺序**（不依赖 HashMap 迭代）。
- 需要玩家决策的技能压入**结算栈帧**，与锦囊/无懈共用 pending：
  - `choice`（是/否二选一，如奸雄）
  - `choose_many`（多选 + 确认/取消，如制衡）
- 技能动作 id：`skill:<code>`（主动技）；多选内部用 `choose:<card_id>` / `confirm` / `cancel`。
- 技能只读引擎状态，不改规则；新技能必须走代码 + 用例（工作台不得改规则，ADR-0016）。

## 8. 实现口径（自动/锁定化的技能）

以下技能规则为「可以」，引擎按**自动发动/锁定化**实现（与观星、克己一致；后续如需改为可选，统一加 `choice` 帧）：

| 技能 | 实现口径 |
|---|---|
| 天妒 | 判定牌生效后自动获得（不再询问） |
| 连营 / 枭姬 | 失去最后手牌 / 装备后自动摸牌 |
| 烈弓（P4.4） | 指定目标后满足条件即自动封锁【闪】（原文「可以」，暂不询问） |
| 红颜（P4.4） | 花色转换按持有者结算（天香/火攻亮牌）；不作全局花色改写 |
| 不屈（P4.4） | 濒死时自动翻「创」，不询问；无牌可翻时不发动 |
| 缠怨（P4.4） | 获得后：不能质疑于吉；体力值为 1 时不能使用/打出手牌（锁定） |
| 八阵（P4.4 火） | 防具槽为空时自动视为【八卦阵】，不询问 |
| 血裔（P4.4 火） | 主公技锁定：其他群势力角色数 ×2 手牌上限，自动生效 |
| 涅槃（P4.4 火） | 濒死时可选发动；弃置所有区域牌 + 复原武将牌 + 摸 3 + 回复至 3 |
| 拼点（P4.4 火） | 双方必须各选一张手牌；同点视为发起者未赢 |
| 帷幕（P4.4 林） | 目标枚举时过滤黑色锦囊牌（物理花色）；不改变牌本身 |
| 完杀（P4.4 林） | 锁定：其回合内除本人/濒死者外不能使用【桃】 |
| 行殇（P4.4 林） | 死亡清理前询问；终局不触发；标记牌不参与 |
| 乱武（P4.4 林） | 限定：自动取第一张【杀】、自动最近目标；不触发目标指定后窗口 |
| 觉醒（P4.4 山） | 准备阶段自动判定；志继的选择用 `AwakenFrame`；已觉醒写 flags |
| 化身（P4.4 山） | 只获得展示武将第一个已实现技能；准备/结束各可替换一次 |
| 固政（P4.4 山） | 弃牌者获得一张、固政者获得剩余（按弃牌列表顺序自动分配） |
| 放权（P4.4 山） | 弃 1 手牌自动取第一张；额外回合后按目标座位正常顺序继续 |

裸衣**不在此列**：它是手动触发（摸牌阶段 `choice` pending，可放弃并正常摸 2 张）。

遗计的口径偏差：规则为「每受到 1 点伤害后」触发，引擎当前**按每次伤害结算触发一次**（多伤事件只发一次）；分配部分已实现（逐张 `target`，可留给自己）。待 P4.2 `damage_before` 窗口统一后改为按点触发。

流离的口径偏差：弃置费用当前限定为**手牌**（不支持弃置装备区的牌），且转移目标不含【杀】使用者与空城角色；待 P4.2 装备/弃牌选择统一后补装备。

判定窗口口径（P4.2 收口）：**铁骑 / 刚烈 / 洛神 / 八卦阵均已接入通用 `judge_before`（`QuickJudge` 帧），全部支持鬼才改判**；与延时锦囊判定共用 `judge_rewrite` pending 与「判定者左手侧起、判定者最后」的询问顺序。P4.4 起 **鬼道** 也走同一帧（黑色手牌过滤），**雷击** 走 `QuickJudge(reason=leiji)`。

P4.4.1 口径与边界（详见 ADR-0023 §3）：天香选项 1 的伤害按普通伤害结算、X 取目标受伤后的已损失体力（上限 5）；神速的虚拟【杀】不计 `sha_used` 且无距离限制；蛊惑扣置牌在结算/作废前不离开手牌；鬼道/鬼才改判暂只支持手牌；解围移动牌暂只能移动到自己的对应区域；神速②只弃手牌装备。
