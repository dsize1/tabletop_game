# 三国杀标准身份局规则

> 状态：**P0 草案 v0.1（2026-10-26）**，依据 `plan.md`、`rules-rulings.md`、`cards.md`、`generals.md` 整理；未确认细节集中在 §12。
> 来源：三国杀官方规则/萌娘百科参考页（`https://mzh.moegirl.org.cn/三国杀/游戏规则`）、用户 2026-10-25 裁定、社区牌表数据。
> 本文只描述**标准身份局**；国战/双将/暗将不在本期范围，但状态与引擎需预留接缝（ADR-0016）。

## 1. 范围与模式

- 人数：**5–8 人**，标准身份局。
- 首版牌池：**标准包 108 张**；军争 52 张已整理（`cards.md`），玩法在 P4 启用。
- 首版武将：标准包（`generals.md` 标准段）；其他包按 P4 逐步开放。
- 端侧：Web 为主交互面（公共区/个人区/特殊区），Q 群只做开局/状态/链接（ADR-0020）。

## 2. 身份与人数

| 人数 | 主公 | 忠臣 | 反贼 | 内奸 | 说明 |
|---|---:|---:|---:|---:|---|
| 5 | 1 | 1 | 2 | 1 | 标准 |
| 6 | 1 | 1 | 3 | 1 | 8 人局减 1 忠、1 反 |
| 7 | 1 | 2 | 3 | 1 | 8 人局减 1 反 |
| 8 | 1 | 2 | 4 | 1 | 标准 |
| 8（双内） | 1 | 1 | 4 | 2 | 双内不结盟 |

- 身份随机分配，**主公身份公开**，其余隐藏。
- 死亡后身份公开（标准身份局）。
- 身份配比数据表见 `data-model.md` 的 `sgs_identity_setup`。

## 3. 胜负条件

- **主公 / 忠臣**：所有反贼与内奸死亡，且主公存活。
- **反贼**：主公死亡（不要求清场）。
- **内奸（含双内）**：除主公外其他玩家全部死亡后，由内奸杀死主公；双内互不结盟，最终只能有一名内奸达成。
- **主公先于其他角色死亡 → 反贼胜利**（双内局同理）。

## 4. 游戏准备

1. 按人数抽取身份牌并分配；主公公开。
2. **选将**（用户 2026-10-26 确认）：
   - **主公先选**：候选 = 全部「主公」武将 + **N 张非主公武将**；N 为配置项（默认 5），后续逐步增加；
   - 主公选完后，**主公未选的武将**（含未选中的主公将）进入**武将池**；
   - **其他玩家同时发放候选**：从主公左手侧开始，每名其他玩家一次性获得 **M 张**候选（M 为配置项，默认 5，玩家之间候选不重复）；各玩家同时从自己的候选中选 1，不是「依次选完再放回池」；
   - 其他玩家未选的候选**回到武将池**（本局不再重发）；
   - 候选/武将池按启用的武将包过滤（`status=live`）；N/M 见 `state-machine.md` 的 `config`。
3. **体力**：
   - 武将 `max_hp` / `initial_hp` 来自中台；
   - **主公体力 = 武将最高体力 + 1，初始体力 = 武将初始体力 + 1**；
   - 官网抓取数据 `initial_hp=0` 视为未提供，按 `initial_hp = max_hp` 处理。
4. 每名玩家初始手牌 **4 张**；牌堆洗混（随机结果入事件）。
5. 主公先手，进入主公的第一个回合。

## 5. 回合流程

一个回合按固定阶段推进；技能可插入/跳过/重复阶段（见 `state-machine.md`）。

```
准备阶段 → 判定阶段 → 摸牌阶段 → 出牌阶段 → 弃牌阶段 → 结束阶段
```

### 5.1 准备阶段

- 触发「准备阶段」相关技能。
- 默认无其他动作。

### 5.2 判定阶段

- 若判定区无牌，跳过。
- 判定区是**栈**：**后放入的牌先判定（LIFO）**。
- 逐张处理：
  1. 从栈顶取出一张延时锦囊；
  2. 亮出牌堆顶一张作为判定牌（判定牌公开）；
  3. 允许改判技能按响应顺序响应；
  4. 判定结果生效：按延时锦囊效果处理（命中则执行，不命中则无效果）；
  5. 该延时锦囊置入弃牌堆（技能另有规定除外）。
- 示例：先【乐不思蜀】、后【兵粮寸断】→ 先判【兵粮寸断】，再判【乐不思蜀】。
- 判定区同一玩家不能同时存在**同名**延时锦囊（如不能再放第二张【乐不思蜀】）。

### 5.3 摸牌阶段

- 默认摸 **2 张**；技能可修改摸牌数或放弃摸牌。
- 牌堆不足时，将弃牌堆洗混作为新牌堆（随机结果入事件）。

### 5.4 出牌阶段

- 玩家可使用任意张牌、发动技能；受以下限制：
  - **每个出牌阶段默认只能使用一张【杀】**（诸葛连弩/技能可突破）；
  - 使用【杀】的目标必须在攻击范围内；
  - 使用牌/技能必须满足牌面与技能条件（距离、目标、资源、次数）。
- 使用牌后按牌面结算；结算完成后的牌置入弃牌堆（装备牌置入装备区，延时锦囊置入判定区）。
- 【桃】：出牌阶段只能对自己使用（回复 1 点体力，满血不可用）；濒死时可对濒死角色使用。
- 【酒】：出牌阶段对自己使用，本回合下一张【杀】伤害 +1（每回合限一次）；濒死时对自己使用，回复 1 点体力。
- 装备牌：置入对应装备槽（武器/防具/进攻马/防御马），同槽旧牌置入弃牌堆；装备技能立即生效。
- 锦囊牌：按目标与距离规则使用；可被【无懈可击】响应（见 §6.3）。
- 延时锦囊：置入目标判定区；置入时可被【无懈可击】抵消；不能被连续放置同名牌。
- 玩家可主动结束出牌阶段。

### 5.5 弃牌阶段

- **弃牌阶段手牌上限 = 当前体力值**（技能可修改；用户 2026-10-26 确认）。
- 若手牌数 > 上限，须弃置至上限（一次弃置多张）。

### 5.6 手牌持有上限

- 任何时刻手牌最多 **20 张**（配置项 `max_hand_cards`，默认 20，可配置）。
- 摸牌/获得牌后若手牌超过持有上限，**立即弃置至 20 张**（弃置选择由玩家；具体交互 P2 细化）。
- 持有上限与弃牌阶段上限相互独立：持有上限是硬上限；弃牌阶段上限仍为当前体力值。

### 5.7 结束阶段

- 触发「结束阶段」相关技能。
- 回合结束，按座位顺序移交下一位存活玩家。

## 6. 牌与结算

### 6.1 基本牌

| 牌 | 使用时机 | 效果 |
|---|---|---|
| 杀 | 出牌阶段 | 对攻击范围内一名角色；目标需打出【闪】，否则受到 1 点伤害。默认每阶段限 1 张。 |
| 闪 | 响应【杀】/需要闪的牌 | 抵消该【杀】/效果。 |
| 桃 | 出牌阶段（自己）/濒死 | 回复 1 点体力；满血不能使用。 |
| 酒 | 出牌阶段/濒死 | 出牌阶段：本回合下一张【杀】伤害 +1；濒死：回复 1 点体力。 |

- 军争的火杀/雷杀造成火焰/雷电伤害；藤甲、铁索连环等按军争规则（P4）。

### 6.2 装备（标准包）

| 装备 | 类型 | 效果 |
|---|---|---|
| 诸葛连弩 | 武器（范围 1） | 出牌阶段使用【杀】无次数限制。 |
| 青釭剑 | 武器（范围 2） | 使用【杀】时无视目标防具。 |
| 寒冰剑 | 武器（范围 2） | 使用【杀】造成伤害时，可防止伤害并弃置目标两张牌。 |
| 雌雄双股剑 | 武器（范围 2） | 使用【杀】指定异性目标后，可令其选择弃一张手牌或让你摸一张牌。 |
| 贯石斧 | 武器（范围 3） | 使用【杀】被【闪】抵消后，可弃两张牌使【杀】仍造成伤害。 |
| 青龙偃月刀 | 武器（范围 3） | 使用【杀】被【闪】抵消后，可再使用一张【杀】。 |
| 丈八蛇矛 | 武器（范围 3） | 可将两张手牌当【杀】使用/打出。 |
| 方天画戟 | 武器（范围 4） | 使用最后一张手牌【杀】时，可额外指定至多两个目标。 |
| 麒麟弓 | 武器（范围 5） | 使用【杀】造成伤害时，可弃置目标一匹坐骑。 |
| 八卦阵 | 防具 | 需要【闪】时判定，红色视为打出【闪】。 |
| 仁王盾 | 防具 | 黑色【杀】对你无效。 |
| 的卢 / 绝影 / 爪黄飞电 | 防御马 | 防御距离 +1（见 §7）。 |
| 赤兔 / 大宛 / 紫骍 | 进攻马 | 攻击距离 +1（见 §7）。 |

> 装备区槽位：**武器 / 护具 / 进攻马 / 防御马 / 特殊区（木牛流马预留）**，每槽各 1；后装备的牌顶掉同槽旧牌并使其进入弃牌堆。
> 装备数值与槽位见 `cards.md`、`data-model.md` 的 `equip_slot` / `range_type`。

### 6.3 锦囊与响应

- **目标规则**：单目标/群体/距离限制见 `cards.md`；不合法目标不可选。
- **无懈可击**：
  - 当一张锦囊即将生效时，任意玩家可打出【无懈可击】抵消；
  - **询问顺序从打出该锦囊牌的玩家左手侧开始**（不是「当前回合玩家」）；
  - 若有人打出【无懈可击】，**重新从原锦囊使用者的左手侧开始**询问是否对上一张【无懈可击】再打出【无懈可击】，可反复嵌套；
  - **允许同一玩家连续多次响应**（不同轮次/不同链节点），不因已响应过而跳过；
  - 响应链结束（无人再打出无懈）后，按抵消层数判定原锦囊是否生效；被抵消的锦囊不生效，置入弃牌堆。
- **南蛮入侵 / 万箭齐发**：按响应顺序，每名其他角色依次打出【杀】/【闪】，否则受到 1 点伤害。
- **决斗**：目标先出【杀】，双方交替出【杀】，先不出者受到对方 1 点伤害。
- **借刀杀人**：目标需对指定角色使用【杀】，否则将武器交给使用者。
- **过河拆桥**：弃置目标一张牌（手牌/装备/判定区，按实现选牌）。
- **顺手牵羊**：获得距离 1 内目标一张牌（手牌/装备/判定区）；该距离**不含武器攻击范围**，受进攻/防御马与技能修正（陆逊等例外）。
- **无中生有**：摸 2 张。
- **桃园结义**：所有已受伤角色回复 1 点体力。
- **五谷丰登**：亮出与存活角色数相等的牌，按当前玩家左手侧顺序每人选 1 张。
- **乐不思蜀**：判定非红桃 → 跳过出牌阶段。
- **兵粮寸断**：判定非梅花 → 跳过摸牌阶段。
- **闪电**：判定黑桃 2–9 → 受到 3 点雷电伤害；否则移动到下一位玩家判定区（需无同名牌）。
- **火攻 / 铁索连环 / 藤甲 / 白银狮子 / 古锭刀 / 朱雀羽扇 / 骅骝**：军争内容，P4 启用（定义已入 `cards.md`）。

## 7. 距离

- **距离无上限**；只计算存活角色，按座位顺时针/逆时针取较小步数；自己到自己的距离为 0，其他至少 1。
- **攻击距离**（你到别人的可达距离）：默认 **1**；武器 `+N`（以武器 `range_value` 为准）；**进攻马 +1**；技能修正（如马超「马术」+1）可与装备叠加。
- **防御距离**（别人到你的距离）：默认 **1**；**防御马 +1**；技能修正叠加。
- **【杀】的距离** = 武器攻击范围 + 进攻马 + 技能修正；目标需在攻击距离内。
- **顺手牵羊/兵粮寸断等**：使用**不含武器攻击范围**的距离（基础座位距离 + 马匹/技能修正）；个别武将技能（如陆逊）可覆盖默认规则。
- 距离计算必须由引擎确定性计算，不接受上游传入的距离；`config` 中的基础距离可配置。

## 8. 体力、伤害、濒死、死亡

### 8.1 伤害

- 伤害包含：来源、目标、点数、伤害类型（普通/火焰/雷电）、是否为属性伤害。
- 伤害结算顺序：造成伤害前 → 扣减体力 → 造成伤害后 → 触发技能。
- 体力不能低于 0；体力为 0 或更低进入濒死。

### 8.2 濒死

- 当角色体力 ≤ 0，进入濒死状态，**暂停当前结算**，按响应顺序（当前玩家左手侧开始）询问是否使用【桃】/【酒】等救援。
- 每回复 1 点体力，若体力 > 0 则脱离濒死；若仍 ≤ 0，继续询问。
- 无人救援 → 角色死亡。

### 8.3 死亡与奖惩

- 死亡角色：身份公开，弃置其所有牌（手牌/装备/判定区），移出座位顺序（不再参与距离/响应）。
- **杀死反贼：摸 3 张牌**（伤害来源）。
- **主公杀死忠臣：主公弃置所有手牌和装备牌**。
- 其他死亡无额外奖惩（P0 已确认）。
- 死亡后立即检查胜负（见 §3）。

## 9. 技能与响应

- 技能分为：主公技 / 一般武将技 / 锁定技 / 限定技 / 觉醒技（`data-model.md`）。
- 技能可修改回合阶段、摸牌数、手牌上限、距离、伤害、响应等；具体技能实现见 P2/P4。
- **响应顺序通用原则**：闪/桃/濒死/改判/技能响应等从**当前玩家（判定者为当前回合玩家）左手侧**开始，按座位顺序循环；死亡角色跳过。
- **无懈可击链例外**：从**打出锦囊牌的玩家左手侧**开始；每次有人打出无懈，重新从原锦囊使用者左手侧开始；允许同一玩家多次响应（§6.3）。
- 锁定技自动生效；限定技/觉醒技按技能描述触发；主公技仅主公可用（或按技能描述）。
- 技能触发必须写入事件；非法/越权技能响应由引擎拒绝。

## 10. 特殊交互区

- 观星、五谷丰登、判定展示、濒死求桃、无懈可击链等属于特殊交互区。
- 全部登记在 `special-zones.md`，未登记不得实现；观星排序在实现阶段落地（`ordered` 原语）。
- 视图三分区：公共局面区（只读）/ 玩家个人资源区（交互）/ 特殊交互区（按可见性）。
