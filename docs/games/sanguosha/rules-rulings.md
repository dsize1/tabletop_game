## 2. 胜负条件

- **主公 / 忠臣**：消灭所有反贼与内奸（主公存活）。
- **反贼**：杀死主公（不要求清场）。
- **内奸（含双内）**：**除主公外其他玩家全部死亡后，由内奸杀死主公**；双内不结盟，各自以此为目标，最终只能有一名内奸达成。
- **主公先于其他角色死亡：反贼胜利**（用户 2026-10-25 确认；双内局同理，不再区分是否有存活反贼）。

## 3. 死亡奖惩

- **主公杀死忠臣**：主公**弃置所有手牌和装备牌**。
- **杀死反贼：摸 3 张牌**（用户 2026-10-25 确认）。
- 其余奖惩（杀死内奸等）暂无特殊规则，按普通死亡处理。

## 4. 响应顺序（通用原则）

- 所有需要响应的判定（**闪、桃/濒死求桃、技能响应等**）**从当前玩家（判定者为当前回合玩家）的左手侧开始**，按座位顺序依次响应。
- 一轮响应完成后若仍可继续响应，继续按同一方向循环，直到无人响应。
- 死亡/离场角色跳过；**无超时**（见 §6）。

### 4.1 判定区（延时锦囊）判定顺序

- 判定区是一个**栈**：**后放入的牌先判定（LIFO，后进先出）**。
- 回合开始进入判定阶段后，从栈顶（最后放入的牌）开始逐张判定并结算；判定完成后该牌按牌面规则置入弃牌堆（技能另有规定除外）。
- 示例：玩家**先被【乐不思蜀】、后被【兵粮寸断】**，则其判定阶段**先判定【兵粮寸断】，再判定【乐不思蜀】**。
- 数据模型：`seats[].judge_zone` 按放入顺序存储，**数组末尾 = 栈顶**；引擎从末尾向前遍历。
- 判定牌的展示与改判响应属于特殊交互区 `judge`（见 `special-zones.md`）；**改判/判定响应从当前回合玩家（判定者）左手侧开始**（用户 2026-10-26 确认）。
- 改判实现口径（P4.1，2026-10-30）：判定牌亮出后自动弹 `judge_rewrite` pending；顺序从判定者左手侧起、**判定者最后**；只询问拥有改判技能且手牌非空的角色；可打出改判牌或 `pass`，后改判覆盖前改判（被替换的判定牌进弃牌堆）。

### 4.2 无懈可击链顺序（用户 2026-10-26 / 2026-10-27 确认）

- 锦囊即将生效时，**从打出该锦囊牌的玩家左手侧**开始，按座位顺序询问**所有存活玩家**（**不因手中没有无懈而跳过**——保留「思考/犹豫」造成的心理博弈，用户 2026-10-27 确认）。
- 若有人打出【无懈可击】，则**重新从打出原锦囊的玩家左手侧**开始，询问是否对上一张【无懈可击】再打出【无懈可击】；可反复嵌套。
- **允许同一玩家连续多次响应**（在不同轮次/不同链节点）；不因已响应过而跳过。
- 响应链结束（**连续一整轮无人再打出无懈**）后，按抵消层数判定原效果是否生效：奇数层 → 被抵消；偶数层 → 生效。
- **AOE 锦囊按目标逐个结算，每个目标各自开一次无懈窗口**，互不影响（B 被无懈不影响 C/D）。
- 无懈链期间打出的无懈置入处理区，链结束后统一放入弃牌堆。
- 死亡/离场角色跳过；无超时。

### 4.3 延时锦囊与判定阶段的无懈（用户 2026-10-27 确认）

- 延时锦囊**置入判定区时不可被无懈可击**。
- 判定阶段对该延时锦囊**先开无懈窗口**（从判定者左手侧起，询问所有存活玩家，规则同 §4.2）；无懈链结束后才亮判定牌。
- **被无懈则不再判定**：
  - 【乐不思蜀】/【兵粮寸断】：直接置入弃牌堆，效果不生效；
  - 【闪电】：不判定、**不置入弃牌堆**，而是**流转到判定者左手边第一个玩家**的判定区；若该玩家判定区已有【闪电】，继续向左手侧找第一个没有【闪电】的存活玩家，绕回自己则弃置（用户 2026-10-27 确认）。
- 未被无懈时按原规则判定：乐/兵按判定结果生效；闪电 ♠2–9 → 3 点雷电伤害并弃置，否则移动到下家判定区。
- 判定牌公开；该窗口在 UI 中属于特殊区 `judge`。

### 4.4 决斗 / 借刀杀人 / 顺手过河 / 五谷（用户 2026-10-27 确认）

- **决斗**：目标先出【杀】，双方交替；**只在决斗开始（即将生效）时开一次无懈窗口**（被无懈则决斗结束，不再要求出杀、不造成伤害）；一旦开始交替出杀，**过程中不再开无懈窗口**（用户 2026-10-27 最终确认）。
- **借刀杀人**：二阶段目标选择——先选**装备区有武器**的角色 A（无武器者不可选），再选 A **攻击范围内**的另一名角色 B（**可以是使用者自己**，只排除 A）；执行前开无懈窗口；**即使 A 没有【杀】也必须询问**（A 显式选择打出哪张杀或不出），不得因无杀跳过，也不得随机代选（不同花色/点数会影响后续结算）。
- **顺手牵羊 / 过河拆桥**：共用特殊区 `pick_card`；可选目标区域 = 装备区（全部槽位，明牌）、手牌（**选择手牌即随机**）、判定区延时锦囊（明牌）。顺手 → 选中的牌进入使用者手牌；过河 → 选中的牌进入弃牌堆。
- **五谷丰登**：特殊区 `wugu`；**释放者先选**，之后按座位（左手侧起）依次选 1 张。
- **改判（2026-10-30 用户确认，P4 落地）**：判定牌亮出后**自动**进入改判 pending；询问顺序**从判定者左手侧起，拥有改判技能者先被询问**（没有改判技能者不询问）；被询问者可打出改判牌替换判定牌或 `pass`。
- **闪电（2026-10-30 用户确认）**：**只能对自己使用**，置入自己判定区；下一回合判定阶段 LIFO 最先判定（后置入的先进栈）。
- **顺手牵羊 / 过河拆桥（2026-10-30 用户确认）**：目标必须至少有一张可拿的牌（手牌 / 装备 / 判定区）；三区皆空者不可指定为目标，相应锦囊在无合法目标时不可打出。
- **麒麟弓（2026-10-30 用户确认）**：装备者的【杀】造成伤害后，可弃置目标一张坐骑（进攻马/防御马，二选一）；可选择不弃置；非【杀】伤害不触发。实现为 `choice` pending（`skill:qilin:horse_offense|horse_defense` / `pass`），仅当目标存活且有坐骑时出现。
- **通用（2026-10-28 修订）**：响应类询问按「是否还有牌可打」分流，适用于无懈链 / 【闪】/ 【杀】（南蛮·决斗·借刀）/ 求桃 / 主公技接力：
  - **无手牌**（且没有八卦阵、主公技等同势力替代选项）的玩家**自动跳过**，不生成 `pending`——手牌数是公共信息，没有牌就没有犹豫空间；
  - **有手牌**时即使手里没有对应牌也**显式询问**（唯一合法动作是 `pass`），保留心理博弈；**不得代选**、不得自动放弃、不得改判他人。

## 5. 体力、手牌、装备与距离

### 5.1 体力

- **主公体力 = 武将最高体力 + 1，初始体力 = 武将初始体力 + 1**。
- 武将数据：`max_hp`（最高体力）与 `initial_hp`（初始体力）；官网抓取数据中 `initial_hp=0` 表示未提供，按 `initial_hp = max_hp` 处理。
- 国战武将的半体力（1.5/2）仅国战模式使用，本期身份局导入时排除。

### 5.2 手牌持有上限与弃牌上限

- **持有上限**：任何时刻手牌最多 **20 张**（配置项 `max_hand_cards`，默认 20，可配置；用户 2026-10-26 确认）。
- 摸牌/获得牌后若手牌超过持有上限，**立即弃置至 20 张**（弃置选择由玩家，P2 细化交互）。
- **弃牌阶段手牌上限**：仍为**当前体力值**（技能可修改），不是 20。
- 两者独立：20 是「持有/摸牌后」的硬上限；体力值是「弃牌阶段」的弃牌上限。
- 示例：甄姬通过技能摸到 25 张 → 摸牌结算后立即弃至 20；弃牌阶段再按当前体力值弃牌。

### 5.3 装备区

- 装备槽位：**武器 / 护具 / 进攻马 / 防御马 / 特殊区（木牛流马预留）**，每槽各 1。
- 后装备的牌会**顶掉**同槽旧牌，旧牌进入弃牌堆。
- 装备技能立即生效；失去装备时对应技能失效。
- 数据模型：`equip_slot = weapon / armor / horse_offense / horse_defense / treasure`（`treasure` 为特殊区预留）。

### 5.4 距离

- **距离无上限**；默认**攻击距离 1**、**防御距离 1**。
- 武器提供 `+N` 攻击距离（以武器 `range_value` 为准）。
- **进攻马 +1 攻击距离**；**防御马 +1 防御距离**（用户 2026-10-26 更正）。
- 武将技能可叠加（如马超自带进攻马 +1，可与装备区进攻马叠加）。
- **顺手牵羊/兵粮寸断等距离**：使用**不含武器攻击范围**的距离（基础座位距离 + 马匹/技能修正）；【杀】的距离 = 武器攻击范围 + 进攻马 + 技能修正。
- 个别武将技能可改变距离计算（如陆逊等），按技能描述覆盖默认规则。
- 距离计算由引擎确定性计算；死亡角色不计入座位距离。

## 6. 长对局与离线

- **无回合超时、无离线判定**；对局可长期挂起，由玩家后续消息/Web 操作恢复。
- 不因玩家长时间不操作自动跳过或判负。

## 11. P4.4.1 火包裁定（2026-10-30）

- **拼点**：发起者与目标各选一张手牌同时亮出；点数 A=1…K=13；**同点视为发起者未赢**；拼点牌进弃牌堆。拼点由玩家选牌（不代选），技能可在此之前选择不发动。
- **八阵（视为装备）**：仅防具槽为空时视为装备【八卦阵】；有实际防具时八阵不生效；青釭剑可无视八阵。
- **涅槃（复原武将牌）**：翻回正面 + 清除武将牌上的标记；**不重置**铁索横置、已用限定技/觉醒等标记。
- **天义**：拼点赢 → 本回合杀次数 +1、使用【杀】无距离限制、可多指定一个目标；没赢/平手 → 本回合不能使用【杀】（含转化与蛊惑声明）。与方天画戟不叠加（最多 3 目标）。
- **鞬出**：使用【杀】指定目标后弃其一张牌；弃装备 → 目标不能【闪】；弃非装备 → 目标获得此【杀】。目标为大乔时**流离优先**，流离后不再触发鞬出。
- **双雄**：摸牌阶段改为判定并获得判定牌；本回合可将**异色**手牌当【决斗】主动使用（不支持响应）。
- **血裔**：主公技锁定，仅袁绍为主公时生效；其他存活群势力角色数 ×2 手牌上限。
- **强袭**：出牌阶段限两次；代价（失 1 体力或弃武器）后对「本回合未以此法指定过」的角色造成 1 伤；代价导致濒死时本次伤害不结算。

## 12. P4.4.1 林包裁定（2026-10-30）

- **行殇**：其他角色死亡时，在死亡清理（弃牌）前询问是否获得其所有牌（手牌/装备/判定区）；终局不触发；武将牌上的标记不参与行殇。
- **巨象/祸首**：南蛮入侵对持有者无效；其他角色使用南蛮时，伤害来源改为存活「祸首」持有者；结算结束后存活「巨象」持有者获得该牌（含被无懈抵消）。
- **再起**：亮 X=已损失体力张牌，红桃数回复体力（不超过上限），获得全部亮出牌，并跳过摸牌阶段。
- **好施**：正常摸 2 后多摸 2；手牌 >5 时选 floor(手牌/2) 张交给手牌最少的其他角色。先选牌再选目标。
- **崩坏**：结束阶段若存在体力低于自己的存活角色，必须失去 1 点体力或减少 1 点体力上限（下限 1）。
- **帷幕**：不能成为黑色锦囊牌的目标（按物理牌花色过滤目标枚举；单体/AOE/借刀/延时一致）。
- **放逐**：受伤后（存活）选一名其他角色翻面并摸 min(已损失体力,5) 张。
- **烈刃**：使用【杀】造成伤害后（目标存活）可与其拼点；赢则获得其一张牌。拼点不覆盖父帧（【杀】）的响应结果。
- **乱武（限定）**：所有其他角色按左手侧顺序二选一：对最近角色使用一张【杀】（自动取第一张，不触发目标指定后窗口）或失去 1 点体力。
- **缔盟**：出牌阶段限一次；选两名其他角色，弃 X=|手牌差| 张后交换其手牌；X=0 直接交换。
- **完杀**：贾诩回合内，除贾诩本人与濒死者本人外，其他角色不能使用【桃】（含急救/蛊惑当桃）。
- **酒池/肉林/截辎/颂威/暴虐**：酒池黑桃手牌当【酒】（含濒死自救）；肉林使涉及董卓与女性的【杀】需 2 张【闪】；截辎在其他角色跳过摸牌阶段后摸 1；颂威在魏势力黑色判定生效后令曹丕摸 1；暴虐在其他群势力造成伤害后令董卓判定，黑桃回复 1。

## 13. P4.4.1 山包裁定（2026-10-30）

- **觉醒**：准备阶段自动判定；志继的选择（回复 1 / 摸 2）用 `choice`；觉醒后减/增体力上限并授予对应技能（急袭/观星/英姿+英魂/激将）。
- **屯田**：回合外失去牌后判定，非红桃判定牌置于武将牌上为「田」；每张「田」距离 -1；红桃判定牌进弃牌堆。
- **巧变**：准备阶段弃 1 手牌并跳过一个阶段（判定/摸牌/出牌/弃牌，准备与结束不可）；跳过摸牌时逐名获得至多两名角色各一张手牌；跳过出牌时移动场上一张牌到自己区域。
- **享乐**：成为【杀】目标后，使用者可弃 1 张基本牌使【杀】继续，否则此【杀】无效。
- **放权**：跳过出牌阶段；结束时可弃 1 手牌（自动取第一张）令一名其他角色执行额外回合；额外回合后按目标座位正常顺序继续。
- **激昂**：使用/成为红色【杀】或【决斗】目标后摸 1（自动）。
- **制霸**：其他吴势力出牌阶段限一次，与孙策拼点；挑战者没赢则孙策从弃牌堆获得两张拼点牌；孙策已发动魂姿时可拒绝。
- **直谏**：将装备手牌置入其他角色对应装备槽（原装备弃置），然后摸 1。

- **清俭**：摸牌阶段外获得牌后触发（每回合只询问一次）；交给一名其他角色**一张**手牌（「任意张」简化为 1），当前回合角色手牌上限 +1（`qingjian_limit`）。
- **界突袭**：获得 X 张即少摸 X 张（X ≤ 2），随后仍跳过摸牌阶段；与标准「放弃全部摸牌」的差异在获得 1 张时体现为仍摸 1。
- **界裸衣**：摸牌阶段亮出牌堆顶 3 张，可跳过摸牌并获得其中所有基本牌/武器牌/【决斗】（其余进弃牌堆）；直到**你的下回合开始**，你为来源的【杀】/【决斗】伤害 +1（`luoyi_bonus`，准备阶段清除）。
- **界遗计**：摸 2 后只能交给**其他**角色（不可留给自己）；「共计至多两张、至多两名角色」按逐张分配实现。
- **恂恂**：摸牌阶段开始观看牌堆顶 4 张，选 2 张按顺序置顶、其余按序置底；之后照常摸 2。
- **忘隙**：造成 1 点伤害或受到 1 点伤害后（仅 1 点伤害事件）触发；摸 2 后必须交给对方其中一张（不询问是否只给一张以外的处理）。
- **界洛神**：黑色判定牌获得后不立即因手牌上限弃置，并计入 `luoshen_free` 使本回合手牌上限 +1/张。

## 23. P4.4.2 一将成名批次 Y1 裁定（2026-10-31）

- **恃勇**（锁定）：受到红色【杀】或【酒】【杀】造成的伤害后，减 1 点体力上限（体力上限不低于 1，体力同步压至上限）；`jiu_boost:<seat>` 记录本张【杀】是否被【酒】加成。
- **自守**：摸牌阶段可选择多摸 X 张（X=全场存活角色势力数），并令本回合你造成的伤害被防止（不区分目标）；跳过则不产生任何效果。
- **宗室**（锁定）：手牌上限 + 全场势力数（与 `kingdom_count` 同口径，至少 1）。
- **权计**：「权」为武将牌上的牌；每受到 1 点伤害触发一次（逐点）：摸 1 张并将一张**随机手牌**置于武将牌上为「权」（自动口径），每张「权」手牌上限 +1。
- **自立**（觉醒）：准备阶段「权」≥3 时强制觉醒：回复 1 点体力（体力已满时不可选）或摸 2 张 → 减 1 点体力上限 → 获得「排异」。
- **排异**（觉醒获得）：出牌阶段限一次，移去一张「权」，令一名角色（含自己）摸 2 张；若其手牌数大于你，你对其造成 1 点伤害。
- **称象**：受到伤害后亮出牌堆顶 4 张（暂存处理区，保证牌数守恒）；逐张选择，点数和 ≤13 才能选入；确认获得入选牌，其余进弃牌堆；可放弃。
- **仁心**：仅「体力值为 1 的其他角色」受到伤害时可用；弃置一张装备牌（手牌或装备区）并翻面，**防止**该次伤害（伤害整体取消，不触发受伤类技能）。
- **精策**：本回合每使用一种**花色**的手牌，手牌上限 +1（花色位图）；出牌阶段结束时摸 X 张（X=本回合使用过的牌的类型数：基本/锦囊/装备，位图去重）。花色/类型按 `play:` 实际使用的手牌记录。
- **峻刑**：出牌阶段限一次；先弃任意张手牌（至少 1）并记录类型集合，再选一名其他角色（需有手牌）；目标二选一：①弃置一张类型与已弃置牌**皆不同**的手牌（目标自选）②翻面并摸「已弃置张数」张。
- **御策**：受到伤害后（存活且有手牌）展示一张手牌；伤害来源二选一：①弃一张与展示牌类型不同的手牌②令你回复 1 点体力。来源无手牌时自动选择②。
- **龙吟**：一名角色**于其出牌阶段内**使用【杀】时，可弃一张牌使该【杀】不计入本阶段使用次数（`sha_used` 减 1）；若该【杀】为红色，关平摸 1 张。可对自己使用【杀】发动。

- **纵适**：拼点结算后自动结算：赢 → 获得点数较小的拼点牌；没赢（含平手/作为目标输）→ 获得自己的拼点牌。拼点牌此时已在弃牌堆，直接取回。
