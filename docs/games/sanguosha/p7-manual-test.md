# 三国杀 P7 群入口人工验收清单

> 口径（ADR-0031 / 2026-11-03 用户裁定）：Q 群只做「开局设定 + 极简局面播报 + 登录链接」；
> 出牌/选将/选目标全部在 Web 完成；群内**不列逐动作选项、不播报公共局面细节、不触发主动消息**。
>
> 验收环境：真实 QQ 群 + 已配置公网 web 地址（`WEB_PUBLIC_URL`）；`#开局` 菜单编号以当前 `games.ts` 为准。

## 1. 命令矩阵（逐条打勾）

| 16 | 动作类命令（`#选`/`#动作`/`#放`/`#重投`/`#单人`/`#小游戏*`） | 一律回「请到网页操作」+ 本人登录链接；不执行、不列动作 | [ ] |

## 2. 链接与消息长度

- [ ] `#开局` / `#加入` **绝不**发登录链接；只有 `#开始` 与 `#网页` / `#局面` / `#恢复` 发。
- [ ] `#开始` 的链接逐人独立，A 的链接不能用于 B（换 token 打开 B 的页面 → 403/无权限）。
- [ ] 5 人局：`#开始` 回执条数 ≤ 2；8 人局：链接自动拆条，单条不超过 700 字符（`sgsLinkMessages`）。
- [ ] 8 人局所有真人玩家都收到链接（含房主）；机器人不签发。
- [ ] 链接 10 分钟有效；过期后 `#恢复` 可重签，旧链接失效。

## 3. 隐藏信息与叙述

- [ ] `#局面` 不出现手牌名/数量明细、他人身份、牌堆顺序、可选动作编号。
- [ ] 三国杀任何回执都不调用 LLM 叙述（`GAME_OPTIONS.sanguosha.narration=false`）。
- [ ] 群消息不带 `pushActive` / 无 `reply_msg_id`（被动回复；`npm run check:proactive-gate` 通过）。

## 4. 真机对局验收

### 4.1 5 人局（1 真人 + 4 机器人，或 2 真人 + 3 机器人）

- [ ] `#开局 三国杀` → `#加机器人 4` → `#开始` → 收到本人链接
- [ ] 点链接进入 Web：选将面板可见 → 选将 → 出牌 → 打完/终局
- [ ] 期间 `#局面` 只回一行 + 链接；不泄露隐藏信息
- [ ] 机器人回合页面显示「机器人行动中…」，服务器自动推进
- [ ] 终局后 `#局面` 回终局摘要；`#开局` 可开下一局（沿用武将包）

### 4.2 8 人局（≥2 真人 + 机器人）

- [ ] 8 人 lobby → `#开始` 链接拆条、每人收到
- [ ] 8 人局公共页布局无横向溢出/座位裁切（浏览器 390/844/1366）
- [ ] 一名玩家阵亡后剩余 AI 继续推进到终局（P6.3 修复）
- [ ] 群消息不超长；无主动消息
