# 界关羽 `sgs_hero_300`（2 技能）

**【1 官方原文】** 出牌阶段限一次，你可以弃置一张牌，然后令一名其他角色展示一张手牌。若此牌为：
•黑色，其本回合非锁定技失效且不能使用或打出手牌，你本回合对其使用的红桃【杀】伤害+1；
•红色，你获得之，然后你可以令其回复1点体力。
来源：`heroes.json#gid=300`

**【2 现实现（按代码陈述）】**
- 出牌阶段主动技（`skill:yijue`，限一次）：①弃置一张手牌（`choose:<id>`）→ ②选一名手牌非空的其他角色（`target:<pid>`）。
- 结算：从目标手牌**随机**取 1 张（`next_index`）展示（写入公共日志，未进公共可见区）。
- 红色 → 该牌进入界关羽手牌；随后**询问界关羽**是否令目标回复 1 点体力（`heal` / `skip`，满血时仍给选项但无效果，直接 `hp += 1` 未走 `flow::heal`）。
- 黑色 → `nonlocked_lost:<target>=1`（本回合非锁定技失效）、`hand_sealed:<target>=1`（本回合不能使用/打出手牌）、`yijue_heart:<target>=1`（本回合对其使用的**红桃**【杀】伤害 +1）。
- 「非锁定技失效」的消费点在 `skills::has` 之外（各技能按 `nonlocked_lost` 自行检查）；`hand_sealed` 由使用/打出入口拦截。
置信度：`verified`（verified=已核对代码路径；inferred=推断，未找到唯一路径）

**【3 与原文差异】**
