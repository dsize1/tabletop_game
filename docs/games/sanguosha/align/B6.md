**【2 现实现（按代码陈述）】**
- 出牌阶段动作 `skill:zhanjue`：前置 = 拥有战绝 && 手牌非空 && `zhanjue_draws` < 2 && 有其他存活角色（`zhanjue_available`）。
- 结算：手牌第一张作为承载牌放入 `processing` 并写 `virtual_defs`=决斗；**其余手牌逐张直接进弃牌堆**；随后 `start_virtual_trick` 进入【决斗】目标选择（与正常使用决斗相同的无懈窗口/结算）。
- 置 `zhanjue_active`；若该【决斗】造成伤害（`zhanjue_on_damage`），刘谌与受伤者各摸 1 张，`zhanjue_draws` 累加**刘谌本次摸到的张数**（每次 1）。
- `zhanjue_draws >= 2` 后 `zhanjue_available` 为假 → 本阶段内动作不再出现（「本技能失效」）。
- 未造成伤害的【决斗】不触发摸牌，也不推进失效计数。
