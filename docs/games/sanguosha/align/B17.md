**【1 官方原文】** 摸牌阶段结束时，你可以选择一项：
 1.摸一张牌，你本回合使用【杀】的次数-1，且【杀】不计入手牌上限；
 2.重铸一张牌，且本回合使用【杀】的次数+1，【杀】无距离限制。
来源：`heroes.json#gid=599`

**【2 现实现（按代码陈述）】**
- v2：`skills::after_draw_phase` 询问（`turn.jiangchi_offered` 每回合一次），选项①/②/放弃。
- ①摸 1 张；`turn.jiangchi_penalty` 使 `Game::sha_limit` 减 1（与其它加成同层相加、可为 0）；`turn.jiangchi_sha_free` 让手牌中的【杀】不计入手牌上限（`hand_limit_delta`）。
- ②从手牌或装备区选 1 张重铸：`to_discard`（计入弃置）→ 摸 1 张；`turn.jiangchi_bonus` 使【杀】次数 +1；`turn.jiangchi_no_distance` 只令【杀】无距离（`skills::sha_no_distance`）。
置信度：`verified`（verified=已核对代码路径；inferred=推断，未找到唯一路径）

**【3 与原文差异】**
- ②「重铸一张牌」v1 只从手牌选，未含装备区。
- ①的「次数 -1」实际会把 `sha_limit` 从 1 减到 0（基础 1 张也不能用），与「仍可使用、只是次数 -1」的意图有落差（除非另有 +X 或连弩）。
- v1 的 `jiangchi_no_distance` 对**所有牌**生效（文本限定【杀】）。
- 「不计入手牌上限」只按手牌中的实体【杀】计数，不含转化牌。

**【4 疑点】**
- `Q1` ②「重铸一张牌」的牌来源？
  - 候选：A. 手牌 + 装备区 / B. 仅手牌（v1 口径）
  - 倾向：**B**（三国杀「重铸」通常指手牌（如铁索连环），且 v1/标准一致。）
  - 影响：候选集合 + 用例。
  - 裁定：**A**

  - 候选：A. 与 +X 同层相加（基础 1 + 加成 - 1，可为 0） / B. 只作用于本回合基础次数（不与其他 +X 同层）
  - 倾向：**A**（mechanics sha-limit 要求统一走 `Game::sha_limit` 的回合计数。）
  - 影响：次数计算 + 用例。
  - 裁定：**A**
- `Q3` ②的重铸是否算「弃置」？
  - 候选：A. 算：走统一弃置入口，触发弃置类技能（旋风/屯田/纵玄等） / B. 不算：重铸只弃不打触发
  - 倾向：**A**（v1 走 `discard_by`；官方重铸同样会触发「因弃置」。）
  - 影响：弃置事件 + 用例。
  - 裁定：**A**
- `Q4` ②的「【杀】无距离限制」是否只作用于【杀】？
  - 候选：A. 只作用于【杀】（文本限定） / B. 本回合所有牌无距离（v1 全局开关）
  - 倾向：**A**（文本明确「【杀】无距离限制」。）
  - 影响：距离入口 + 用例。
  - 裁定：**A**
- `Q5` ①的「【杀】不计入手牌上限」如何判定？
  - 候选：A. 手牌中牌定义为【杀/火杀/雷杀】即不计（v1 口径） / B. 转化后的【杀】也不计（按生效定义）
  - 倾向：**A**（与既有手牌上限豁免口径一致（按牌属性判 def）。）
  - 影响：手牌上限 + 用例。
  - 裁定：**A**

**【6 动画 / UI 期望】**

**断言**
- 正例：①摸 1、本回合【杀】次数 -1、杀不计手牌上限；②重铸（弃 1 摸 1）、次数 +1、【杀】无距离

- 延时锦囊（乐不思蜀/兵粮寸断）**不适用 ±1 且不消耗该效果**（用户 2026-11-10 修订：废除延时锦囊的额外目标支持）。
- 没赢：`plan_use` 拦截所有锦囊（含延时锦囊）。
