## 制霸（`zhiba` / lord）— `implemented`

**【1 官方原文】** 主公技，出牌阶段限一次，你可以与一名其他吴势力角色拼点；其他吴势力角色出牌阶段限一次，其可以与你拼点（你可以拒绝）：若其没赢，你可以获得两张拼点牌。
来源：`heroes.json#gid=452`

**【2 现实现（按代码陈述）】**
- v2：主动技（主公技）——孙策出牌阶段限一次，选一名手牌非空的吴势力角色拼点（`kernel::pindian`）。
- 拼点后按 `PindianResult` 判定：挑战者没赢（含平局）→ 孙策从弃牌堆获得两张拼点牌（走 `gain`）；已被取走则少拿。
- 每阶段放弃后不再提示（`phase.cancel_zhiba`）。
- 拼点牌经 `gain` 从弃牌堆获得；不在弃牌堆的牌不补摸。
- **他人侧（2026-11-11 实现，`rules-rulings §46` / ADR-0041）**：吴势力角色**自己出牌阶段限一次**可发起挑战
  （`turn.zhiba_challenge:{座位}`，**拒绝也计次**）；持有者（主公）被询问「接受拼点 / 拒绝」，**可无条件拒绝**；
  接受 → `pindian::start(挑战者, 持有者)`，挑战者没赢（含平局）→ 持有者获得两张拼点牌。
  拼点前提：双方都有手牌、持有者存活且当主公（主公技身份闸门）。
置信度：`verified`（verified=已核对代码路径；inferred=推断，未找到唯一路径）
