## 骄矜（`jiaojin` / normal）— `implemented`

**【1 官方原文】** 当男性角色对你造成伤害时，你可以弃置一张装备牌，然后此伤害-1。
来源：`heroes.json#gid=327`

**【2 现实现（按代码陈述）】**
- 触发在「造成伤害时」（伤害**尚未**结算，与天香/仁心同一时机）：受伤者拥有骄矜、来源是**男性**角色、来源≠自己、且受伤者有装备牌（手牌里的装备牌或装备区牌）。
- 询问：列出「手牌中的装备牌 + 装备区的牌」+「不发动」；选定后弃置该牌（装备区的牌会触发旋风/枭姬类失去装备钩子）。
- 发动后伤害 -1（下限 0）；减到 0 时**不再结算伤害**（不产生伤害事件，「受到伤害后」类技能不触发）。
- 不发动 → 按原伤害立即结算。
- 女性来源、无来源伤害（闪电等）不触发。
置信度：`verified`（verified=已核对代码路径；inferred=推断，未找到唯一路径）

**【3 与原文差异】**
- 「男性角色」读来源武将性别；来源为无（闪电/失去体力）时不触发 ✓。
- 成本「一张装备牌」实现含**手牌里的装备牌**与装备区牌 ✓（旧引擎 legal/execute 曾不一致，已修）。
- 伤害减为 0 时完全不结算 → 若把「0 点伤害」也算「受到过伤害」，会影响勇略/佐定等按伤害事件判定的技能。

## 佐定（`zuoding` / normal）— `implemented`
