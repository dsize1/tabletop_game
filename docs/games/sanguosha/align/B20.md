置信度：`verified`（verified=已核对代码路径；inferred=推断，未找到唯一路径）

**【3 与原文差异】**
- 界版是「获得两名角色各一张牌」，v1 只从 B 获得一张并交给 A。
- 界版「然后你展示一张牌并交给其中手牌较少的角色」，v1 没有该第二步（也未展示）。

  - 倾向：**A**（原文「两名角色」+界版语义（安恤他人）；含自己会与「手牌较少者」冲突。）

  - 倾向：**A**（「然后」表示获得之后再比较。）
  - 影响：比较时点 + 用例。
  - 裁定：**A**
- `Q4` 「你展示一张牌」的范围？

  - 倾向：**A**（原文「然后你展示一张牌并交给其中手牌较少的角色」——「其中」指两名角色之间，展示牌应是刚获得的牌。）
  - 影响：选牌 + 用例。
  - 裁定：**A**
- `Q5` 「若不为黑桃」的判定与后续？
  - 候选：A. 按展示牌的有效花色（`effective_suit`）；非黑桃 → 安恤者摸 1 张 / B. 按被获得牌的原花色
  - 倾向：**A**（展示的是交出的那张；花色读取统一入口（红颜等覆盖同样生效）。）
  - 影响：花色入口 + 用例。
  - 裁定：**A**

## 追忆（`zhuixi` / limited）— `verified`

**【1 官方原文】** 限定技，结束阶段，你可令一名其他角色摸三张牌并回复1点体力。然后你死亡时，可以对其再次发动本技能。
来源：`heroes.json#gid=775`

**【2 现实现（按代码陈述）】**
- v2：`PhaseStart(End)` + `Window::OwnPhase(End)`；限定技（`flags.zhuixi_used`）每局一次，选定目标后 `draw(3)` + `flow::heal(1)`，并记 `zhuixi_target`。
- 亡语：`skills::on_death` → `b20::on_death` 在死亡清理前压入询问，只能对首次目标再次发动（`draw 3 + heal 1`）；独立一次、不排除杀死者。
- 满血时 `flow::heal` 不回复（仅摸牌）。
置信度：`verified`（verified=已核对代码路径；inferred=推断，未找到唯一路径）

**【3 与原文差异】**
- v1 没有限定技「每局一次」的状态（每个自己的结束阶段都可再问）。
- 「你死亡时，可以对其再次发动」未实现（死亡钩子缺失）。
- 「对其再次发动」的目标（首次选择者 vs 任意角色）需确认。
- 回复体力 v1 直接改 `hp`（v2 必须走 `flow::heal`）。

**【4 疑点】**
- `Q1` 「然后你死亡时，可以对其再次发动本技能」的目标？
  - 候选：A. 只对**首次发动时选择的**那名角色（记住目标） / B. 任意其他角色（重新选择）
  - 倾向：**A**（原文「对其」指首次选定的角色。）
  - 影响：状态记忆 + 死亡钩子 + 用例。
  - 裁定：**A**
- `Q2` 限定技状态口径？
  - 候选：A. 结束阶段发动一次为「已用」；死亡时的再次发动是独立的一次（不受已用限制） / B. 死亡时的再次发动也受「每局一次」限制（首次已用则不能再次发动）
  - 倾向：**A**（原文「再次发动本技能」明确给了第二段，若受同一限制则该句无意义。）
  - 影响：flags/计数 + 用例。
  - 裁定：**A**
- `Q3` 死亡时发动与死亡结算的时序？
  - 候选：A. 死亡结算前（步练师已死亡但仍可发动；目标在其死亡后获得牌/回血） / B. 死亡结算后（不可再发动）
  - 倾向：**A**（「你死亡时」即死亡事件发生时；mechanics `dying-resolution` 之外需要死亡钩子。）
  - 影响：死亡钩子入口 + 用例。
  - 裁定：**A 此类技能称之为亡语，使用统一钩子，在濒死后死亡的角色在离开游戏前执行该技能**
- `Q4` 死亡时目标是否排除杀死者？
  - 候选：A. 不排除（可对杀死者发动） / B. 排除杀死者（v1 结束阶段口径）
  - 倾向：**A**（原文仅写「对其」，未排除；v1 的 killer 过滤来自标准版文本。）
  - 影响：候选集合 + 用例。
  - 裁定：**A**
- `Q5` 回复 1 点体力在满血时？
  - 候选：A. 不回复（`flow::heal` 不能超过上限） / B. 可超过上限
  - 倾向：**A**（统一回复入口口径。）
  - 影响：回血入口 + 用例。
  - 裁定：**A 仅摸牌**

**【5 机制依赖】** `limit-skill`、`card-gained`、`wording-then`、`turn-window`

**【6 动画 / UI 期望】**
- 提示文案：追忆（限定技 · 亡语）：结束阶段令一名其他角色摸三张并回复 1；你死亡时可对其再次发动｜浮层交互：结束阶段选目标（可放弃）；死亡时（离开游戏前）提示再次发动｜动效 key：memory_light｜逐张亮牌：无｜群侧播报：播报摸牌/回血与死亡时再次发动
