## 0. 两个维度：怎么进游戏 / 什么时候结算

**进入时机**

| 时机 | 含义 | 板块 |
|---|---|---|
| `OnBet` 下注时 | 在该小游戏对应赌场**下注**即进入。**下注有两种形态**：`place:{n}`（掷骰后下注）与 `sg:D2:use:{n}`（D2 特权下注） | A1、A2、B2、D1、D2、E1、E2、F1、F2、G2、H1、H2 |
| `OnFifthDie` 放第 5 颗 | 自己下注后该场颗数达 5 | C1 |
| `RoundSettleWinner` 结算阶段·该场胜者 | 结算阶段按赌场顺序，该场「移除平手后第一名」进入 | B1、G1 |
| `TurnAction` 回合内 | 持有者回合主动使用（D2 的回合替代投掷） | D2 |
| `Setup` 设置阶段 | 每轮开轮时摆放灰骰/标记 | F1、F2（分组）、G1（摸彩）、H1（格位） |
| `Passive` 持续 | 只影响排名/可用性 | D2、E1、E2、F1、F2 |

**结算时机（`SgTiming`）**

| 码 | 时机 | 板块 |
|---|---|---|
| T1a | 下注后**自动**立即结算 | A2、C1、D1、E2 |
| T1b | 下注后**交互**（多段 pending；同次下注多个交互会**排队**） | A1、B1、B2、E1、F1、F2、G1、G2、H1、H2 |
| T3 | 结算阶段·逐赌场（移除平手前） | C2 |
| T4 | 结算阶段·交互（做完恢复结算） | B1、G1 |
| T5 | 钞票分配后·统一结算 | G2（游戏场）、H1（格位）、H2（金框） |

> 结算阶段顺序（2026-10-17 裁定）：进入结算 → **按赌场 1→6** 跑 B1/C2/G1（同场顺序 B1 → C2 → G1）→ 正式逐场结算（1→6）→ 分配后统一结算（G2/H1/H2）→ 下一轮。

## 2. 跨板块通用规则（对局中最容易踩的）

1. **「下注」= `place:{n}` 或 `sg:D2:use:{n}`**，两者都触发所有「下注后」小游戏。
2. **大骰口径**：赌场计数是**等效权重**（大骰=2），但**颗数判定**（C1、G2 的 N、H2/F2 的取骰）大骰只算 1 颗。
3. **取骰优先级统一**：从手牌/酒吧/金框取或放时**优先小骰**；只剩大骰则整颗处理，**原样还原**（大还大）。
4. **灰骰（虚拟玩家）**：参与「移除平手 / 比多少 / D2 唯一最多」，**不领钞票**，不能持有特权；**摆放灰骰不是下注**，不触发任何下注时判定。
5. **E1 禁止**只拦「自己骰子下注 + D2 特权放置」；F2/B1/H1/灰骰不受影响。
6. **所有小游戏状态每轮重置**（除玩家资产：钞票/筹码）；**同一轮内**只有 C1 名额、A2 指示物、E1 箭头、F1 分组、F2 格位这类板块内状态持续。
7. **加密选项**（A1 单选 / G1 多选）：代码只在本人牌面页映射真实含义，群里只发代码；页面 token 对加密选项场景 5 分钟有效，过期发 `#恢复` 重签。
