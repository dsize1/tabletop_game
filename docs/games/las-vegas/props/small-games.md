# 道具：小游戏板块（Small-Game Tiles，A1–H2）

> 状态：**已实现（阶段 3a 自动/结算类 + 3b 交互类）**。来源：用户规则 二.1 / 四 / 五.1 / §7 白话小游戏 + 攻略（动作打分）。
> 实现见 `crates/engines/las-vegas/src/sg.rs`；动作 id 见 `legal-actions.md` §1.C。

## 基本属性

- 共 **16 块**梯形板块，编号 A1、A2、B1、B2、C1、C2、D1、D2、E1、E2、F1、F2、G1、G2、H1、H2。
- 抽取流程 **16→8→N**：先每个字母组 A–H 各随机取 1 个（16→8），再从 8 个中随机取 **N 个**（N∈3–6）作为本局小游戏池；再分配到 1、2、3 号赌场下。
- 触发：通常在该小游戏对应的赌场**下注后可激活**；B1 例外（每轮分配钞票前激活）；F1/F2/G1 含「赌盘设置阶段」的初始摆放。

> 用户已确认：**16→8→N**（每字母组随机取 1，再随机取 N∈3–6）。因每字母组只取 1 个，**F1/F2 天然互斥**（不会同局共存）。
> 【用户裁定 2026-10-16】N **默认 3**，由房主 `set_small_game_count` 设定；**每轮重新 16→8→N**；抽中的 N 块从 1 号赌场起依次挂载（第 i 块 → `((i-1) mod 3)+1` 号赌场）。

## 数据模型映射

- 每轮：`casinos[0..3].small_games: Vec<SmallGameId>`（挂到 1–3 号赌场，N>3 时可多块），来源为**每轮重新** 16→8→N 的抽取结果。
- 各小游戏的状态（标记归属、灰色骰位置、金框/游戏场/酒吧内容）落在 `LasVegasState` 的小游戏子状态中（见 `data-structure.md`）。
- 抽牌（哪 3 块）与灰色骰摆放结果须作为事件写入（随机或设置阶段动作）。

## H1 好骰难求：格位与骰子流转（用户裁定 2026-10-17）

- 状态：`sg.h1_slots: Vec<Option<H1Slot{owner, dice, big}>>`（长度 6，索引 0–5 ↔ 格 1–6）；`dice` = 格内颗数（**大骰也只算 1 颗**），`big` = 其中大骰颗数；每轮 `setup_round` 重置为空。
- 触发：仅在**下注到挂 H1 的赌场**后 → pending `H1`（`stage="post_bet"`），动作 `sg:H1:use` / `sg:H1:skip`。
- `use`：从该赌场 `dice[玩家]` 取 1 颗（**不是手里**）：**优先小骰**，无小骰时**大骰整颗取走**（权重 -2，不拆半）→ **重投** `roll_die` → 点数即格号 → 入格；大骰入格与小骰同价（**只算 1 颗**）；该骰**不参与该赌场钞票分配**、不回手牌。
- 挤位：格内已有**他人**骰子 → 对方整批移到「格号对应赌场」（格 n ↔ n 号赌场；不触发任何小游戏，含 C1 第 5 颗；**D2 特权重算**例外）；挤回的大骰按 2 点权重还原；自己占 1 颗；同一玩家可同格叠加数量。
- 奖励：1 格→1 筹码，2 格→2 筹码，3–6 格→$3/4/5/6 万钞票；多颗按颗数叠加（钞票格每颗各 1 张）；**无条件获得**（不要求赢得对应赌场）。
- 结算时机：逐场钞票分配 + C1 兑换之后，与 G2 游戏场 / H2 金框一同在 `settle_extras` 结算，随后清空格位。

## A1 幸运之拳：牌面页加密选项（用户裁定 2026-10-17）

- 状态：`sg.pending.data = {initiator, perm:[枚数×3], codes:[代码×3], count}`；**公共视图抹除 `perm`/`count`**（`codes` 可公开，无映射无意义）。
- 个人视图：`sg.a1_options = {game,stage,options:[{code,count,reward}]}`，**仅 `player_view` 下发**。
- 动作：`sg:code:{代码}`（群里 `#选 <代码>`）→ `sg:A1:guess:{1..3}`（左手玩家猜）。
- 时效：加密选项页 token **300 秒**；过期发 `#恢复` 重发提示并重签。
- 奖励：猜错按实际枚数 → 1 枚 = 2 筹码、2 枚 = $3 万、3 枚 = $4 万；猜对无奖励。3 枚标记、不可藏 0、不可放弃。

## B1 主场时间：结算阶段进入（用户裁定 2026-10-17）

- 进入：全场手中骰子用尽 → 结算阶段先算 B1 所在赌场「移除平手后第一名」（非灰骰）→ 该玩家进入一次。
- 状态：`sg.pending{game:"B1", actor:胜者, stage:"place", data:{black:[a,b]}}`；`sg.b1_done` 每轮一次。
- 动作：`sg:B1:put:{1..6}` —— 放「掷出点数中等于该赌场号」的 **0–2 颗**黑骰作为**自己**的骰子；0 颗选项文案写「0 颗」以示区别。
- 顺序：B1 → G1 → 逐场结算（黑骰已计入赌场骰数，并重算 D2 特权）。

## A2 大奖挑战：状态与档位（用户裁定 2026-10-17）

- `sg.indicator`：指示物 0-based 格位；**每轮（三轮之一）开始时重置**，轮内持续累积。
- 6 格奖励为**钞票** `[3,4,5,6,7,8]` 万；中奖拿当前格并退回第 1 格；未中前进一格，**到顶不循环**。
- 无交互：`Tempo::OnBetAuto`，`place` 回复直接给黑骰与结果摘要。

## C1 掌声响起：颗数判定与名额（用户裁定 2026-10-17）

- 判定：**颗数**（大骰只算 1 颗）；只看自己颜色、只看「自己下注」路径；黑骰/灰骰/小游戏放骰都不算。
- 名额：`sg.c1_winner: Option<玩家>`，**每轮一个**，先到者得；每轮重置。
- 奖励：**立即** $10 万钞票（取消标记两步流程）。

## 结算阶段统一顺序（用户裁定 2026-10-17）

1. 进结算 → 2. **按赌场顺序 1→6** 跑「结算阶段进入」的小游戏（同赌场内 B1 → C2；`pre_settle_pass`）→ 3. G1 → 4. 正式逐场结算（1→6）。
2. C2：只统计**有骰子**的玩家（0 颗不参与不罚）、并列最少都付、灰骰无视、每场每轮一次（`sg.c2_done`）。
3. 支付：**先钞票（大面额起，银行找零）→ 再筹码**；最多扣到 0，不产生欠款、不追溯。

## D1 发薪愉快：统计口径（用户裁定 2026-10-17）

- 只数 `casinos[].dice` 中**自己的**骰子（本场权重 ≥1 即算）；禁止赌场也算。
- 酒吧/游戏场/金框/H1 格位/手中骰子**不算**。
- 1–2 场 → 对应筹码；3–6 场 → 场数 × $1 万钞票。

## D2 权力优势：归属与特权回合（用户裁定 2026-10-17）

- 判定：仅在**主动下注**时；用**等效权重**比，**必须唯一最多**；平手即淘汰 → 标记回游戏场；灰骰不参与。
- 其他加骰路径（B1 黑骰、H1 挤出、F2 放/收、G2 移出）**只参与结算，不重算归属**。
- 持有者回合：**不掷骰**、无「弃回合」；`sg:D2:use:{1..6}` 放 1 颗（小骰优先，仅剩大骰则权重 2），E1 禁止赌场不可选；放置**触发**该赌场小游戏，完成后推进回合。
- 状态：`sg.privilege: Option<玩家>`（`None` = 在游戏场）；每轮重置。

## E1 禁止进入：箭头与禁止范围（用户裁定 2026-10-17）

- 箭头环形 6 格：`[无, 2 筹码, 无, $3 万, 无, 1 筹码]`，**按前进后位置**领奖；初始第 1 格。
- `sg:E1:ban:{1..6}`（排除本场赌场与已禁止赌场）→ 箭头 +1 并领奖；`sg:E1:pass` → 放弃（不动箭头、无奖）。
- 禁止只拦「自己下注 + D2 特权放置」；F2/B1/H1/灰骰不受影响。初始无禁止标记；**所有小游戏状态每轮重置**（无跨轮，除钞票/筹码）。

## E2 醉倒了吗：酒吧状态（用户裁定 2026-10-17）

- `sg.bars: BTreeMap<玩家, BarDice{small,big}>`（按骰型分别记录，收回原样还原）。
- 引擎代取骰：其他人各取 1 颗（**优先小骰**），酒吧已满 2 颗则跳过；手中无骰跳过；触发者不放并收回自己酒吧全部。
- 大骰在酒吧算 1 颗；不参与任何赌场结算；**不跨轮**。
- 触发时机 = **每次下注**（普通 `place:` 与 D2 特权 `sg:D2:use:` 都算）。

## F1 阻止他：分组与门禁（用户裁定 2026-10-17）

- 分组 `[1,1,2,2,3]`（共 9 颗），每轮重置；放置后该组清空不可再选。
- 门禁：分组全空 → 不进入游戏（不挂 pending）。
- 两步交互：`sg:F1:group:{0..4}` → `sg:F1:move:{g}:{1..6}`（任意赌场，含 E1 禁止场）。
- 灰骰参与结算与 D2 判定（可把玩家挤成非唯一 → 标记回游戏场），但**摆放灰骰不触发任何下注时判定**；特权跟随持有者直到下次下注重算。

## G1 黑色摸彩箱：面额与多选分堆（用户裁定 2026-10-17）

- 面额 `[2,2,6,0,0,0]` 万（钞票，共 10 万）；公共视图脱敏为 0。
- 进入：结算阶段按赌场顺序，该场「移除平手后第一名」为赢家。
- 分堆：左手玩家用**牌面页加密代码多选**（`#选 代码1，代码2`）放入 A 堆，其余进 B 堆。
- 选堆：赢家**明文** `#选 a` / `#选 b`。
- 加密选项能力已通用化：`sg.pending_options{game,stage,multi,options[]}`（A1 单选 / G1 多选）。

## G2 双倍颁奖：移入颗数可选（用户裁定 2026-10-17）

- 触发：下注到 G2 赌场（含 D2 特权下注）；**每次下注**都可。
- 选择：`sg:G2:move:{0..N}`（N = 自己在该赌场的**颗数**，大骰算 1 颗）；**0 = 放弃**；移入时先小骰后大骰（大骰权重 2）。
- 结算：游戏场 = 第七个赌场（移除平手→比权重），第一 $6 万、第二 $3 万；只算移入的骰子；与原赌场分配互斥。

## H2 我的抉择：村规与金框（用户裁定 2026-10-17）

- 掷 2 颗黑骰（**不出现 4,4**）；**4 点 = 村规重掷两骰再选**（不再触发别的小游戏）。
- 选项按可用性过滤：5 点需「手中有骰 或 场上有自己骰」；6 点需「手中有骰」；全不可选 → 不进入游戏并播报。
- 5 点二段式：放入（任意点数、不触发小游戏）/ 收回（任意赌场）；手中无骰直达收回。
- 金框：`GoldFrame{owner, small, big}`，取骰优先小骰、只剩一颗不论大小；置换时**按原骰型退还**；在框内得 $6 万（每轮一次）；不跨轮。

## B2 50% 的机会：格位阶梯（用户裁定 2026-10-17）

- 格位奖励 `[无, 无, 1 筹码, $3 万, $4 万, $6 万]`（0–5）。
- 进入：标记 0 → 先掷 2 骰（基准）→ 免费到第 1 格 → 每轮选 大/小/弃权。
- 猜对前进一格（到第 5 格立即领 $6 万）；猜错**结束且无任何奖励**（含和相等）；弃权按**当前格**结算。
- 状态：`sg.b2_pos` / `sg.b2_prev`；每次激活从 0 重新开始，不跨轮。

## H1 好骰难求（2026-10-17 修订）

- 第一段选**来源**：该赌场里自己已下注的骰子 **或** 手中骰（优先小骰）。
- 第二段**自选格位 1–6**（取消「重投定格」）。
- 挤位：原占用者骰子回「格号对应赌场」，大还大、小还小。

## 遗留项 / 待对齐（2026-10-17 盘点）

### 1. F2 危机就是转机（**已实现 2026-10-17**）

规则见 `rules.md` §7.1「F2 危机就是转机（重做版·用户裁定 2026-10-17）」。实现要点：

- 设置：灰骰直接写入 `casinos[i].dice["gray"]`（1–3 号 +1、4–6 号 +2），参与赌场排名但不领钞票。
- 状态：`sg.f2_slots: Vec<Option<u8>>`（len 9；组 **a = 索引 0–1 / b = 2–4 / c = 5–8**，容量 2/3/4）；`sg.gray` 已删除。
- 动作链：`sg:F2:take:{c}` → `sg:F2:group:{a|b|c}` →（c 组）`sg:F2:put` / `sg:F2:takeback` → `sg:F2:put:{1..6}` / `sg:F2:takeback:{c}`；**不可放弃**。
- 组满不可选（动作描述里标注「已满：x」）；c 组额外校验 `c_usable = 手中有骰 || 有非禁止赌场存自己的骰`。
- 手中无骰 → 跳过「放入/收回」选择直达 `c_takeback`；收回动作只列「自己有骰子」的赌场。
- 放入/收回均**优先小骰**、大骰整颗（权重 2 / 回 `big_remaining`）；E1 禁止赌场不列入动作；放入不触发该赌场小游戏（C1 第 5 颗不算）；两者都重算 D2 特权。

### 2. H2 我的抉择：金框的大骰

规则：金框里有他人骰子 → **还给对方**（回手牌，不是回赌场）。现状 `sg.gold_frame: Option<(玩家, 颗数)>` 无大小骰区分，退还时一律 `small_remaining += n`，大骰会「脱小」。若要与 H1 同样严格，需改为 `GoldFrame{owner, dice, big}` 并按颗还原到 `big_remaining`。
