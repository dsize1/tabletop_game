## 1. 实物版图（据实物照）

- 形态：**六边形骰盘**，6 条边 = 6 个赌场，中央为骰盘（内六边形）。
- 每条边：一枚黄色大骰标示**赌场编号 1–6**；边面用于堆骰；外侧挂小游戏板块（规则仅 1–3 号位置）。
- 6 家店名（顺时针，起点见实物照，**待核定**）：Plaza 廣場 / Golden Nugget 金塊 / Marina 海灣 / Sands 日落 / Miracle 奇蹟 / Circus 馬戲。
- 实物照：`v2-50fd530c...jpg`（赌场版图）；封面：`v2-f07f5d5...jpg`。

## 2. 数字版图坐标（`apps/web/src/view/board/theme.ts`）

| 常量 | 值 | 说明 |
|---|---|---|
| `BOARD_W` | 760 | 逻辑宽（手机竖屏优先，等比缩放） |
| `HEX` | `cx=380, cy=360, rOuter=340, rInner=108` | 外框 / 中央骰盘 |
| `CASINO_RING_R` | 258 | 赌场牌中心到棋盘中心距离 |
| `CASINO_ANGLES` | `[-90,-30,30,90,150,210]` | 6 张牌的角度（正上方起顺时针） |
| `CASINO_CARD` | `220×150, r=12` | 圆角矩形（不保留异形轮廓） |
| `PLAYER_PANEL` | `352×150, 2 列` | 玩家面板 |
| 画布高 | 动态 | `748 + 行数×164 + 公共区` |

- `casinos[i]`（引擎数组下标）→ `CASINO_ANGLES[i]`（牌位）→ `CASINO_NAMES[i]`（店名）。
- **待核定**：实物照中黄色骰点数与 `i` 的对应关系（需逐张核对照片，确认后写死在本文件与 `CASINO_NAMES` 注释里）。

## 3. 素材口径

| 资产 id | 来源 | 尺寸（发布） | 体积目标 |
|---|---|---|---|
| `tile:{A1..H2}` | 16 张板块照片（`A1-幸运之拳.jpg` …） | 宽 640、高随宽高比（紧裁，无透明留白） | 13–21KB/张 |
| `cover` | `cover.jpg` | 460×230 | ≈10.5KB |
| `board` | `board.png`（ComfyUI 清理版） | 760×760 | ≈40KB |

- 原图（含「知乎 @Eric Siu」水印）**不入库**；产物写 `apps/web/public/board/`（git 忽略）+ `manifest.ts`。
- 加工：透视校正 → 旋转校正 → 圆角矩形裁切 →（SDXL inpaint 去手/桌面/水印）→ WebP 压缩 → 质检（SSIM / 标识复读）。
- 映射以板块印字 `A1–H2` 为准（如 F1 板面为 `攔截它 / Block It!`，引擎名「阻止他」，二者不参与匹配）。
