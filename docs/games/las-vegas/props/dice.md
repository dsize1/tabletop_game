# 道具：骰子（Dice）

> 状态：草案 v0.2。来源：用户规则 二.3 / 四 / E2 / F1 / F2 / A2 / B1 / B2 / H2。

## 1. 小骰（Small Dice）

- 每位玩家持有**同色**小骰 **7 枚**（用户规则 二.3）。
- 六面，点数 1–6；投掷后按点数整组下注。
- 颜色集合【待确认】；数据模型中以「颜色/玩家标识」抽象，不依赖具体色名。

## 2. 大骰（Big Dice）

- 每位玩家持有同色大骰 **1 枚**（用户规则 二.3）。
- **仅赌场**（钞票分配 / 移除平手 / 比数量）中 **1 大骰 = 2 小骰**（用户规则 四 + 用户确认 2026-10-13：只有赌场算 2）。
- **其他任何情况（酒吧/小游戏区/金框/游戏场）大骰一律按 1 计数**（酒吧已有明确规定 E2，其余同理，用户确认）。

## 3. 灰色骰（Gray Dice，虚拟玩家）

- 归属银行，视为**虚拟玩家**，可参与「移除平手」与「权力优势」（用户规则 F1/F2）。
- **关联小游戏：F1（阻止他）、F2（危机就是转机）**。
- 初始摆放（由入选的小游戏决定）：
  - **F1**：按小游戏图案放置 **9 颗**灰色骰子；
  - **F2**：1–3 号赌场各 1 颗、4–6 号各 2 颗（共 9 颗）。
- **冲突已消除**：小游戏抽取为「每字母组 A–H 各取 1」（16→8），故 F1/F2 **天然互斥、不会同局共存**，两套灰骰摆法只会有其一。
- 【待确认】F1 图案的确切 9 格位置。

## 4. 黑色骰（Black Dice）

- 触发类小游戏投掷用，**每次 2 颗**。
- **关联小游戏：A2（大奖挑战）、B1（主场时间）、B2（50% 的机会）、H2（我的抉择）**；四者均为「投 2 颗黑骰」的同类需求。
- 结果处理各见 `rules.md` §7。
- **无冲突**：同属「投 2 颗黑骰」，可**共用银行黑骰池**；对 bot 而言按需取用即可，**不设实体库存上限**（每字母组只取 1 个，同局最多同时出现 A2/B*/H2 三类黑骰游戏）。

## 5. 数据模型映射

- 引擎状态中骰子以**数量/点数集合**表达，不逐枚建模个体（同色同规格无差异）：
  - 玩家手中：`small_remaining`、`big_remaining`；
  - 当前投掷：`roll: { small: Vec<u8>, big: u8 }`；
  - 赌场落点：`casinos[i].dice[player|"gray"]`（大骰以权重 2 参与结算，酒吧以权重 1）。
- 掷骰/抽放（灰骰、黑骰）结果须作为事件写入（见 `data-structure.md` / ADR-0004）。
