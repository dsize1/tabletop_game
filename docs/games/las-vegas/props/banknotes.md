# 道具：钞票（Banknotes）

> 状态：草案 v0.2。来源：用户规则 一 / 二.2 / 四 / 五 / C1 / D1。

## 基本属性

- 用途：各赌场奖池；终局按其**总金额**计分（与筹码×$1 万相加）。
- 结算前**背面朝上隐藏**，仅可见张数、不可见面额（引擎内部持有）。
- 每轮洗混后随机抽出 **6 组、每组 2 张**，按组总金额降序铺到 6→1 号赌场（用户规则 二.2）。

## 面额档位

用户规则中出现的最小/最大面额线索：$1 万（D1 换算单位）、$3 万、$4 万、$5 万、$6 万、$8 万、$10 万（C1/G1/G2/H2 奖励）。具体钞票面额档位与各档张数**【待确认】**。

| 面额 | 说明 | 来源 | 验证状态 |
|---|---|---|---|
| $1 万 | D1 计费单位；筹码计分单位 | 用户规则 D1/一 | 用户规则 |
| $3 万 | A2 指示物回位格 / F2 / H1 / H2 | 用户规则 | 用户规则 |
| $4 万 / $6 万 / $8 万 / $10 万 | G1 摸彩 / G2 / C1 / H2 奖励 | 用户规则 | 用户规则 |
| 其它档位与张数 | 待补充 | 待确认 | 【待确认】 |

## 平局判定

- 组间比较：总金额高者更高；总金额相等时，**单张面额较大**的一组更高（用户规则 二.2）。
- 场间结算：骰子最多者拿**面额最高**的钞票、第二多者拿**次高**（用户规则 四）。

## 数据模型映射

- 以 `u32` 存面额（单位：万或元，需统一，建议「元」以避免小数）；结算按面额降序分配。
- 洗牌/发牌结果必须作为事件写入，保证复盘可确定性重放（见 ADR-0004）。
