# 道具：钞票（Banknotes）

> 状态：草案 v0.2。来源：用户规则 一 / 二.2 / 四 / 五 / C1 / D1。

## 基本属性

- 用途：各赌场奖池；终局按其**总金额**计分（与筹码×$1 万相加；1 筹码 = 1 分 = $1 万）。
- 结算前**背面朝上隐藏**，仅可见张数、不可见面额（引擎内部持有）。
- 每轮洗混后随机抽出 **6 组、每组 2 张**，按组总金额降序铺到 6→1 号赌场（用户规则 二.2）。

## 面额档位

【用户裁定 2026-10-17，据攻略《关于"拉斯维加斯"桌游的近乎优胜解策略研究》】钞票分布为 **$3–$10 万**，张数如下（共 90 张）。每轮从全部 90 张重洗，随机抽 6 组、每组 2 张（共 12 张）铺到 6 个赌场。

| 面额 | 张数 | | 面额 | 张数 |
|---|---|---|---|---|
| $3 万 | 11 | | $7 万 | 13 |
| $4 万 | 11 | | $8 万 | 11 |
| $5 万 | 13 | | $9 万 | 9 |
| $6 万 | 15 | | $10 万 | 7 |
| **合计** | **90 张** | | | |

- **来源**：攻略（作者据豪华版实物统计）；用户 2026-10-17 裁定以此为准（取代先前「$1–9 万各 10 张」）。
- 得分池 = Σ(面额×张数) = 562（单位 $万）+ 筹码 30 = **592**（与攻略一致）。
- 攻略「钱币得分加权表」即「两张钞票组合 (a,b) 的出现概率（%）= P(a)% × P(b)% ÷ 100」（存档 `memory_palace/artifacts/las-vegas-score-weight-table.jpg`），供 AI 期望值打分用。

## 平局判定

- 组间比较：总金额高者更高；总金额相等时，**单张面额较大**的一组更高（用户规则 二.2）。
- 场间结算：骰子最多者拿**面额最高**的钞票、第二多者拿**次高**（用户规则 四）。

## 数据模型映射

- 以 `u32` 存面额（单位：万或元，需统一，建议「元」以避免小数）；结算按面额降序分配。
- 洗牌/发牌结果必须作为事件写入，保证复盘可确定性重放（见 ADR-0004）。
